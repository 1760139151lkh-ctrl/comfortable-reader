# 来源与署名

本项目从既有的本地 Comfortable Reader 阅读器演进，保留 EPUB 分页、多栏、CFI 批注及随书学习；本次吸收独立书源、按需获取、浏览器适配和创作工具。设计、编程与示例起草过程中使用了 AI 辅助，具体修改仍由维护者核对。这段说明不把某个工具设为每本书的固定作者，也不授予第三方材料再分发权。

原创教学示例中的数字是明确的人造数据，不冒充真实测量；引用外部资料时保留作者/机构、题名、页段与链接。第三方阅读与渲染依赖的许可见 desktop/THIRD_PARTY_NOTICES.md 及随附许可证。

公开前应由权利人填写项目署名、许可证和纳入清单。源代码、原创文本、媒体、数据和字体分别审核；公共仓库不包含私人书库、对话研究材料、批注、代码草稿或个人运行记录。
