# 内容、活动与个人状态 · v1

这是项目约定，不冒充 EPUB 官方扩展标准。普通 EPUB 保留正文、来源和活动说明；增强能力不可用时，书籍仍可读。

## 一份源内容，多个产物

book.json 持有从创作开始稳定不变的 UUID、修订、章节、资源、来源和活动。书内对象各有唯一 ID，不包含机器路径。chapters/*.md 是简单源项目的正文；图片、代码和数据通过项目内相对路径引用。当前工具支持标题、段落、列表、表格、代码、公式文字及 @source、@resource、@image、@activity。不支持的结构必须报错，不能静默删减。

复杂数学、PDF 与现成 EPUB 仍走保真流程。已有 EPUB 可保持完整字节，由兼容工具抽出实际 spine 章节和声明式学习包；该接口不授予公开许可。不能先下载整个 ZIP，再隐藏部分章节而声称按章获取。

构建生成完整 EPUB，以及同一次导出的独立 XHTML、CSS 和插图。reader.format=epub-stream@1 描述入口、成员身份、每章 readingDocument、readingDependencies 及 epubjs-locations-1000@1 位置表。网页使用共享 EPUB 渲染器，原 JSON 文档树仅保留为构建检查产物，不是另一阅读入口。

资源由字节数与 SHA-256 固定。reader.contentDigest 是所有非目录 EPUB 成员（除 mimetype）按 UTF-8 文件名字节排序后的 [name, bytes, sha256] 数组，以无额外空白的 UTF-8 JSON 编码后计算的 SHA-256。包含 META-INF/container.xml；网页和本机分别核对成员清单/字节，不能只信出版者声明的 ZIP 哈希。实际取得的每个成员仍单独校验。

## 章节与选择范围

小型 catalog.json 只列书籍简介、章节标题、清单入口及清单哈希。进入一本书才读取完整清单，进入一章只读取当前 XHTML、必要插图与元数据，不预取未选择的相邻章节。全书位置表在构建时生成，网页不会为计算位置而遍历所有正文。

资源记录用途名称、所属章、来源、权利状态、大小、哈希、最小获取单位及可选分块。选择书籍正文、章节、活动或资源时，计算必需依赖闭包。可选材料默认不选，清单先显示新增量、已缓存项与用途。按哈希复用分块，失败或暂停可重试；不能裁小模型或替换原始数据来掩盖不可切分的下载。

来源元数据独立于大文件。未下载原件时，仍显示题名、作者/机构、版本、页段、支持的论断、原始链接和条件。没有再分发权的原件保留合法外链或私人绑定，不提供虚假的下载按钮。

公共内容缓存与个人状态分开。取消固定只释放无其他固定引用的字节，不删除个人记录。浏览器存储可能被系统回收，永久保管需要显式导出。原型网页的当前来源数据库可在“⋯ → 接续旧网页记录”中合并；原库只读保留，旧标题锚点不会伪造为精确 CFI。跨来源只能在原地址导出。

## 活动与呈现

活动声明章内锚点、问题、输入、参数、观察目标、产物与版本化能力。例如 least-squares@1 在浏览器 Worker 中执行宿主内置算法，明确不执行书中 Python。新书复用能力只需声明内容；新能力另行实现和测试。

.crlearn 学习包描述图像、音视频、ASCII PLY、来源、代码和参考结果。教学提示、参数名称与枚举说明、参考记录对应关系属于书籍；宿主复用编辑器、图表、播放器、三维舞台与保存逻辑。详细字段见技能的 learning-pack-tools.md。

run_definition_json 声明 python-cli@1 的入口、输入、参数规格、超时、依赖包名称及可选适配。它是待审查声明，不能携带本机解释器、shell、cwd、环境变量或自授信任。宿主本地绑定固定定义、输入/源码哈希和已有解释器；界面打开后代码或配方变化，运行时重新核对。见 [NATIVE-ACTIVITIES.md](NATIVE-ACTIVITIES.md)。

## 位置与更新

翻页/滚动与外观独立，按书保存。CFI 与内容身份绑定；布局变化尽量回到同一段落或元素，不用旧像素位置冒充语义位置。新正文使用独立位置与批注记录，旧版完整保留；打开原版可恢复，不按书名删除重导。

草稿、运行收据、参考结果与回放步骤分别标识。改参数只标旧结果过期，不自动运行。跨端记录使用 comfortable-reader-personal@1 文件，同 UUID、同内容身份才合并；冲突保留双方，导入草稿进入历史，运行收据只读，大产物留在原设备。目前没有自动上传或跨端同步。


## 保留复杂排版的语义书源

`sourceFormat: "epub-source@1"` 使用 `epubSource.root` 与 `epubSource.files` 正向列出可编辑的 XHTML、MathML、CSS、PNG、OPF 与目录文件。`chapters[].href` 指向 OEBPS 内的实际章节。`rich_book.py` 校验包身份、内部链接、禁止执行/外部隐式加载和材料哈希，`export_epub.py` 按固定顺序与时间戳打包；`build_site.py` 从同一个 EPUB 取得按章文件。这一路不会将数学退化为纯文本，也不在每本书中复制阅读器。

已经迁移的复杂书以这些语义文件作为公开正文维护源。材料中的旧 Markdown 引用是固定历史参考，不是另一份需要同步编辑的公开正文。新书仍优先从独立原稿开始；不要把此次旧书兼容迁移变成每次必须先进私人 Calibre 的创作步骤。

可选 `studySource` 指向惰性随书学习源；构建时绑定实际 EPUB 哈希和当前资源字节。这里的 `registered: false` 不是运行授权。原生环境与信任批准仍只在读者设备上建立。资源有各自 `license`、`sourceUrl` 与 `attribution`，总许可证不能覆盖第三方例外。
