# 本次公开了什么

正式书目包含七本具有连续教学内容的作品：人工智能原理、数学定理等价性、有限元方法、智能优化算法、模糊规划、综合评价方法、运筹学建模。短小的格式演示仅保留在 examples，不占正式书籍入口。

《人工智能原理》公开修订 1.0.0 保留导读与 47 章。正文的 4,636 个 MathML 数学结构与迁移前逐项相同。计算公式、已有实验数值和参考代码没有为了界面对齐而改写；本机路径、生成包嵌入原稿和公开许可说明单独处理，私人原件不变。

AI 书有 519 份可分发的声明材料，以及 7 项可以继续在 Windows 上准备与绑定的原生活动。另两项“追踪一个真实 batch”“完整训练与检查点恢复”需要尚未纳入公共版的 WikiText 原文本数组。它们的完整源代码、运行定义和限制保留在书源中；公共界面不把缺少输入的活动当作已就绪。第 34 章三维原件与既有几何查看能力保留，不以静态截图代替。

这些限制属于公共发行范围。已有私人材料和已登记活动不被删除或改成公共版。公共修订的内容身份与原私人修订不同；旧批注保留在旧版记录，不静默贴到改变后的文档。

每项材料的精确许可和来源见 [AI 书 RIGHTS.md](../books/ai-principles/RIGHTS.md) 与 [resource-rights.json](../books/ai-principles/resource-rights.json)。许可说明曾写“仅本机研究”的旧来源记录保留历史含义；本次公共发行依据新的逐项登记，不由那份旧记录自动扩权。
