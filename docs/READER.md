# 从书页开始

已有用户继续打开安装版舒适阅读书库；可从 [Release](https://github.com/1760139151lkh-ctrl/comfortable-reader/releases/latest) 取得已发布的 Windows 安装包，或按开发说明运行同源网页。访问权限和公共站点状态以当前设置为准。安装包未签名；核对来源与同页 SHA256SUMS 后安装。

安装后打开“发现书籍”，在书目地址中填入 `https://1760139151lkh-ctrl.github.io/comfortable-reader/catalog.json`。连接只读取公共书目，不上传私人书库。可以在线打开某章，也可以先从网页下载 EPUB，再在桌面导入；相同 UUID 和实际内容身份用于核对它们的关系。

从书库点书会把它加入当前阅读空间，已打开的书会直接回到它的位置。“并排读”是同一个简单的添加入口；也可直接抓住书卡，拖到正文旁边。拖动时看到的是松手后的真实区域：靠边形成左右或上下排列，两书之间可以插入，已有书拖到另一书中央会交换位置。按 Escape 取消，书库搜索与浏览位置保留。

书页左右留白处可点击翻页，靠近时出现方向提示。正文仍可选字、复制和操作链接。横向翻页会将鼠标滚轮归并为翻页意图；连续阅读保持上下滚动，代码、表格和面板先使用自己的滚动区。方向键走一页，PageUp / PageDown 走一屏；输入和交互控件保留自己的按键。

工具在正文之外。安静时左上角只留淡化的书库与阅读工具入口；在这里稍作停留即可使用目录、排版和查找，点击“阅读工具”或 F8 展开批注、主题、随书学习等操作。点正文或 Escape 收起临时工具。工具区左端的抓手可拖到顶部或底部，松手才停放。排版面板顶部“正在调整”直接选择哪本书，也可点每本书标题旁的“排版”。同一层即可改变这本书的阅读方式、每屏页数和字号；字体、行距、宽度与界面控件大小在同页展开，不会改变其他书。主题共享。

书库中的“全部”和“正在读”共用同一个紧凑面板，切换时不会再叠一块管理浮层。“正在读”按内容缩短高度；书名和作者保持单行，较长的末端渐隐。靠近书卡才显示详细进度和并排动作，添加书籍与扫描详情在标题旁的加号中展开，真实错误会直接展开提示。

书库、目录、排版与批注面板可拖标题移动、拖边缘缩放；靠近左右边缘后松手停靠，也可点击标题旁的停靠按钮。停靠会为正文留出真实空间。书库宽度受阅读空间约束，不为显示完整书名撑大。窄窗暂时把面板放回可见范围，变宽后恢复原安排。面板的抓手与右下角也支持键盘方向键，抓手上的 Home 恢复面板位置。

“专注一本”临时放大当前书，“返回对照”恢复原排列。书库中的“正在读”列出全部打开的书，也提供不用拖动的位置调整。顶端不横排书名；较长的书名与目录项在末端渐隐，悬停可读完整名称。Ctrl+1…9 选择相应书籍。最多保留12本；空间不足时显示当前书与切换入口，其他书仍然打开，变宽后恢复原布局。关闭阅读区域保留书籍与位置；下次启动恢复仍打开的书、主动调整的面板几何和仍停靠的面板。浮动的临时面板不会在启动时一起弹出。当前不提供同一本书的两个独立位置视图。

全屏时直接抓住顶部空白向下拖，松手回到窗口；也可双击顶部空白，或按 F11。这里不画抓手或提示线。靠近右上角才显示最小化、回到窗口和保存关闭，键盘也能聚焦这些操作。窗口状态继续使用系统标题栏。

底部进度在靠近或键盘聚焦时变得清楚；拖动先显示目标，松开后才跳转。“恢复阅读布局”只整理书籍与工具位置，不清空书库、字号、进度或批注。

目录和搜索定位到正文中的内容；返回箭头回到跳转前的位置。打开活动、原图或资料后，使用“返回书页”回到原处。阅读位置自动保存，和离线保存文件是两件事。

原文标记、自由文字与手写笔迹属于书页批注。“随书学习”中的本书笔记跨章保存，每条保留所属章节和原句；可以关联当时的运行或媒体时间。网页与桌面各自保存个人记录，没有默认跨端同步。更多菜单可导出记录，在同书、同内容身份下导入；冲突保留双方，代码导入不授予执行权。

更多菜单中的“本章离线保存”会列出正文和必要材料；全书正文、某个活动、独立资源分别选择。内置计算缺输入时才打开准备清单。已有字节按哈希复用；暂停保留已核分块。取消离线固定、清理未使用缓存不删除个人批注、代码和运行记录。浏览器存储可能被系统回收，长期保管请另行导出。

“下载电子书 · EPUB”取得现成的完整文件。它保留正文、插图、出处和活动说明；运行环境与独立大型材料不随文件附带。在其他 EPUB 阅读器里，活动链接仍能打开文字说明。

源码定位只表示正在读哪一行。轨迹回放来自已经保存的运行，不表示代码重新执行。结果显示运行编号和代码版本；参数或草稿变化会标明旧结果。返回书页时本机任务继续，点击“停止运行”会结束任务；退出应用会结束尚未完成的本机进程树。

网页中的内置计算无需 Python。Python、PyTorch 和长任务使用 Windows 桌面的已绑定环境；网页可看源码、写草稿、查参考材料。原生程序具有当前用户的文件与网络权限，进程组、超时和虚拟环境不是安全沙箱。准备材料、安装环境、批准代码、开始运行分别处理。

书籍换版后，每份内容拥有自己的位置与书页批注，旧记录在“版本记录”中保留。恢复原版内容可以找回它自己的记录。软件不会把未经核对的旧 CFI 或批注直接贴在改变后的正文上。
