# 从书页开始

已有用户继续打开安装版舒适阅读书库；可从 [Release](https://github.com/1760139151lkh-ctrl/comfortable-reader/releases/latest) 取得已发布的 Windows 安装包，或按开发说明运行同源网页。访问权限和公共站点状态以当前设置为准。安装包未签名；核对来源与同页 SHA256SUMS 后安装。

安装后打开“发现书籍”，在书目地址中填入 `https://1760139151lkh-ctrl.github.io/comfortable-reader/catalog.json`。连接只读取公共书目，不上传私人书库。可以在线打开某章，也可以先从网页下载 EPUB，再在桌面导入；相同 UUID 和实际内容身份用于核对它们的关系。

书库用于选书，进入正文后只保留阅读工具。书名右侧选择翻页或连续滚动；翻页可以设置同屏栏数。字号、行距、宽度和主题在 Aa 中调整。阅读方式按书保留，窗口变窄不会自行换方向。

目录和搜索定位到正文中的内容；返回箭头回到跳转前的位置。打开活动、原图或资料后，使用“返回书页”回到原处。阅读位置自动保存，和离线保存文件是两件事。

原文标记、自由文字与手写笔迹属于书页批注。“随书学习”中的本书笔记跨章保存，每条保留所属章节和原句；可以关联当时的运行或媒体时间。网页与桌面各自保存个人记录，没有默认跨端同步。更多菜单可导出记录，在同书、同内容身份下导入；冲突保留双方，代码导入不授予执行权。

更多菜单中的“本章离线保存”会列出正文和必要材料；全书正文、某个活动、独立资源分别选择。内置计算缺输入时才打开准备清单。已有字节按哈希复用；暂停保留已核分块。取消离线固定、清理未使用缓存不删除个人批注、代码和运行记录。浏览器存储可能被系统回收，长期保管请另行导出。

“下载电子书 · EPUB”取得现成的完整文件。它保留正文、插图、出处和活动说明；运行环境与独立大型材料不随文件附带。在其他 EPUB 阅读器里，活动链接仍能打开文字说明。

源码定位只表示正在读哪一行。轨迹回放来自已经保存的运行，不表示代码重新执行。结果显示运行编号和代码版本；参数或草稿变化会标明旧结果。返回书页时本机任务继续，点击“停止运行”会结束任务；退出应用会结束尚未完成的本机进程树。

网页中的内置计算无需 Python。Python、PyTorch 和长任务使用 Windows 桌面的已绑定环境；网页可看源码、写草稿、查参考材料。原生程序具有当前用户的文件与网络权限，进程组、超时和虚拟环境不是安全沙箱。准备材料、安装环境、批准代码、开始运行分别处理。

书籍换版后，每份内容拥有自己的位置与书页批注，旧记录在“版本记录”中保留。恢复原版内容可以找回它自己的记录。软件不会把未经核对的旧 CFI 或批注直接贴在改变后的正文上。
