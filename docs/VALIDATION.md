## 当前实际边界

- Windows 安装包未签名；未执行全新物理电脑、macOS 或 Linux 的原生安装验收。浏览器可用与本机 Python 可用分别判断。
- 未取得再分发条件的 Penn Action 等材料保留来源入口。公共版没有可播放的那两段视频；安装版曾测试它们，不等于已获公网分发权。
- 两项 WikiText 原文数组依赖活动在公共版尚不能直接准备；完整定义和源码保留，不以演示数据替换。其他原生活动需在读者设备重新检测环境和批准代码。
- 未重新训练整本书的所有模型。书中参考结果标为作者已有实验，新的用户运行另存，不将历史成绩当成本次重新训练。
- 没有自动跨端同步、付费服务、自动依赖安装或训练。浏览器缓存可能回收；长期保存个人记录应主动导出。
- 模式匹配扫描和小样渲染不能证明不存在所有秘密、法律问题或教学错误。来源、技术结论与正文仍接受持续审阅和更正。

首次浏览器检查曾发现纯标题被单独拆成短章；已把这些标题/引导并入后续内容，并重新完成 21 处检查。另一检查中发现外部来源卡含 9 个 Google 网站图标；公共版去掉装饰图标，保留真实引文和来源链接，避免隐式请求。


## 0.6 多书工作区

本轮在现有共享界面重构了空间布局和操作入口，保留 EPUB 渲染、内容锚点、批注与随书学习适配。新增布局不变量测试覆盖单书占位、三书主辅、移动交换、稀疏窗格、手动比例序列化及窄窗不覆盖原布局。

浏览器回归使用真实本地 EPUB、隔离状态和模拟原生 IPC，覆盖搜索/返回、Auto/3/4/10 页、逐页/整屏、60 次尺寸调整、三书独立排版、拖动预览/交换、专注与窄宽恢复、关闭重开笔记、第五本不替换、刷新恢复。DOM Range 用于 CFI/批注自动验证；实际指针选字另在原生窗口验证，二者不是同一种证据。

复现：先构建共享界面；`node --test tests/workspace-layout.test.mjs`。真实书回归另需已有书库的只读快照和 Playwright：指定 `READER_BASELINE` 与可选 `PLAYWRIGHT_PATH`，运行 `node tests/reader-workspace-browser.cjs`。它只在内存中保存测试进度、把截图与报告写入忽略的 work 目录，不修改生产书库。

当前明确限制：最多打开 12 本不同书籍；不提供同一本书的独立双视图。空间不足时切换阅读，恢复窗口或主动重新整理可恢复共显。固定多页模式仍保留原逻辑画布，适合概览；Auto 更适合调整区域后的连续阅读。安装包未签名。复杂内容采用代表性段落验证，不宣称逐页人工审完全部藏书。


本机最终安装版已核对安装程序解包与已安装可执行文件的完整 SHA-256；三本真实书籍、手动分割比例和各自 CFI 在退出/重新启动后完全一致。真实窗口已执行选字、原文标记、比例拖动和专注往返；生产记录没有写入合成测试批注。布局重排改用已挂载章节，自动检查确认 iframe 在 Auto 尺寸调整后仍连接；真实窗口复查重排显示。真实复杂内容抽样另覆盖《算法导论》的矩阵、长公式、原图与图注，以及 AI 教材的代码和表格，宽/窄区域截图及几何检查保存在本机验收目录。

测试层次：68 项结构/单元检查，13 条模拟 IPC 的真实书阅读旅程，4 类复杂内容场景；本机安装版另有完整文件身份、实际入口、书库扫描、手动操作与恢复证据。代表性抽样不等于逐页审阅所有藏书。独立双视图、其他操作系统原生安装及长期人类阅读舒适度仍未验证或未提供。

本轮75项结构/单元检查通过；原有13条真实书模拟IPC阅读旅程通过，新增14组连续流程覆盖安全工具区、页边翻页、滚轮归并、书库拖出/取消/插入、单面板书库、标题渐隐、面板移动缩放与真实停靠、进度预览、独立字号、窄窗和恢复。另有6组模拟原生窗口检查，覆盖空白顶边下拖、取消、双击、窗口边界、按需窗口操作和保存后关闭顺序。

Windows实际安装验证与浏览器分开记录。0.7系列安装构建实际执行了从书库加入三本不同书、调整比例与交换、移动缩放与停靠面板、翻页/键盘/连续滚动、独立字号、目录跳转返回和重开。最终0.7.5在实际普通窗口中核对了约27%宽度的书库、长标题/作者渐隐，以及在同一书库内切换并缩短的正在读列表。最终安装包与已安装程序逐字节绑定；正常保存关闭并重开后，三本书的CFI、排版偏好、空间树和面板状态完全一致。原有12本书、14条进度和批注保留，36个书库文件哈希未改变。

真实全屏空白顶边下拖恢复、双击恢复、右上角恢复与保存关闭已验证。更窄的480/640 CSS窗口与DPR2在浏览器中验证，不能冒充切换了Windows显示设置；本轮原生最窄窗口的边框调整尝试未取得可用证据。实体触控板、跨显示器移动、其他操作系统原生安装及长期人类舒适度仍未验证。窗口最小化的操作路由已做模拟检查，未单独执行最终安装版最小化验收。

复杂公式、代码、表格、原图/图注采用真实材料的代表性抽样；真实绑定学习资料、代码和WAV的打开、静音播放/暂停与返回也已检查，没有执行书中Python程序。对应检查读取真实内容，但原生IPC和个人记录隔离，不等于逐页审完所有藏书。较早一次关闭面板后立即滚轮未移动的触发原因尚未确定；后续10次不同间隔轨迹及最终连续阅读流程通过，不将未复现写成已证明根因修复。
