第二章　标准路线：先分清你说的“模糊”是什么

前一章说明了一个软要求为什么不能只靠“存在某个满意度变量”来约束。现在把问题放回模糊规划理论本身，区分软约束、模糊参数、模糊目标和硬约束。

现在把视线从某一种个人写法移开，直接看经典模糊规划理论通常怎样处理这类问题。

先把最关键的一点钉死：

λ\lambda 不是模糊规划必然存在的变量。
它只在某一类特定模型——“最大化最低满意度”模型——中作为辅助变量出现。

很多模糊规划问题根本不需要 λ\lambda。

一、首先要区分两种完全不同的“模糊”

现实里说“大约”“最好不要超过”，可能对应两种数学含义。

1. 软约束

例如：

成本最好不超过 100 万，最多可以容忍到 120 万。

这里的 100 和 120 都是已知的，问题不是数据不确定，而是“超过一点也可以接受”。

通常写成：

C(x)≲100.C(x)\lesssim 100.

定义满意度：

μC(x)={1,C(x)≤100,120−C(x)20,100<C(x)<120,0,C(x)≥120.\mu_C(x)= \begin{cases} 1,&C(x)\le100,\\[4pt] \dfrac{120-C(x)}{20},&100<C(x)<120,\\[6pt] 0,&C(x)\ge120. \end{cases}

这是模糊约束或软约束。

2. 模糊参数

例如：

单位成本大约为 100 元。

这里连成本系数本身都不确定，可以写成模糊数：

c~=(90,100,120).\tilde c=(90,100,120).

这种问题需要处理模糊系数、模糊数、α\alpha-截集、可能性与必然性等。

你前面主要问的是第一种：目标和某些约束是否允许部分满足。下面重点讨论这一类。

二、精确目标 + 少数模糊约束 + 其他精确约束

这是你提到的第一种情形。

标准形式是：

max⁡f(x),s.t.gj(x)≤0,j=1,…,m,hi(x)≲bi,i=1,…,r.\begin{aligned} \max\quad &f(x),\\ \text{s.t.}\quad &g_j(x)\le0,\qquad j=1,\dots,m,\\ &h_i(x)\lesssim b_i,\qquad i=1,\dots,r. \end{aligned}

其中：

  • f(x)f(x) 是精确目标；

  • gj(x)≤0g_j(x)\le0 是硬约束；

  • hi(x)≲bih_i(x)\lesssim b_i 是软约束。

问题在于：

hi(x)≲bih_i(x)\lesssim b_i

本身还没有定义一个普通的可行域。

你必须告诉模型：

软约束至少要满足到什么程度？

标准做法主要有下面三种。

标准做法 A：给定满意度水平 α\alpha

这是最直接、最常用的做法。

决策者选定：

α∈[0,1].\alpha\in[0,1].

要求：

μi(x)≥α,i=1,…,r.\mu_i(x)\ge\alpha, \qquad i=1,\dots,r.

于是模型变成：

max⁡f(x),s.t.gj(x)≤0,μi(x)≥α.\boxed{ \begin{aligned} \max\quad &f(x),\\ \text{s.t.}\quad &g_j(x)\le0,\\ &\mu_i(x)\ge\alpha. \end{aligned} }

这里唯一要最大化的仍然是：

f(x).f(x).

完全不需要 λ\lambda。

线性软约束的确定化

假设：

ai⊤x≲bia_i^\top x\lesssim b_i

允许最多违反 pip_i，隶属度为：

μi(x)={1,ai⊤x≤bi,bi+pi−ai⊤xpi,bi<ai⊤x<bi+pi,0,ai⊤x≥bi+pi.\mu_i(x)= \begin{cases} 1,&a_i^\top x\le b_i,\\[4pt] \dfrac{b_i+p_i-a_i^\top x}{p_i}, &b_i<a_i^\top x<b_i+p_i,\\[6pt] 0,&a_i^\top x\ge b_i+p_i. \end{cases}

要求：

μi(x)≥α.\mu_i(x)\ge\alpha.

在过渡区间内就是：

bi+pi−ai⊤xpi≥α.\frac{b_i+p_i-a_i^\top x}{p_i}\ge\alpha.

整理得：

ai⊤x≤bi+pi(1−α)\boxed{ a_i^\top x \le b_i+p_i(1-\alpha) }

因此原问题直接变成普通优化：

max⁡f(x),s.t.gj(x)≤0,ai⊤x≤bi+pi(1−α).\begin{aligned} \max\quad &f(x),\\ \text{s.t.}\quad &g_j(x)\le0,\\ &a_i^\top x\le b_i+p_i(1-\alpha). \end{aligned}

解释如下：

  • α=1\alpha=1：完全不允许违反，恢复为 ai⊤x≤bia_i^\top x\le b_i；

  • α=0.8\alpha=0.8：只允许使用 20%20\% 的容忍范围；

  • α=0\alpha=0：允许一直到 bi+pib_i+p_i。

这就是标准的 α\alpha-水平法。

标准做法 B：把满意度和原目标看作多目标

有时决策者不知道该选：

α=0.6,0.8,还是 0.9.\alpha=0.6,\quad0.8,\quad\text{还是 }0.9.

那么问题本质上就不是一个单目标问题，而是：

max⁡f(x)\max f(x)

同时希望：

max⁡μ1(x),…,max⁡μr(x).\max\mu_1(x),\dots,\max\mu_r(x).

标准写法是一个多目标规划：

max⁡(f(x),μ1(x),…,μr(x))\boxed{ \max \bigl( f(x), \mu_1(x), \dots, \mu_r(x) \bigr) }

满足所有精确约束。

因为这几个目标通常冲突，所以不会自然产生唯一答案，而会得到一组 Pareto 最优解。

例如：

  • 方案 A：利润高，但软约束满意度低；

  • 方案 B：利润稍低，但软约束满意度高。

然后决策者从中选择。

在数值计算中，通常采用：

  • ε\varepsilon-约束法；

  • 加权和法；

  • 字典序法；

  • 生成 Pareto 前沿。

标准做法 C：扫描不同的 α\alpha

这在实际建模里非常常见。

分别令：

α=0, 0.1, 0.2,…,1,\alpha=0,\ 0.1,\ 0.2,\dots,1,

对每个 α\alpha 求：

F(α)=max⁡{f(x):μi(x)≥α, gj(x)≤0}.F(\alpha) = \max\{f(x):\mu_i(x)\ge\alpha,\ g_j(x)\le0\}.

最后得到一条曲线：

α⟼F(α).\alpha\longmapsto F(\alpha).

它回答：

如果我要求软约束满足得更严格，最多会损失多少目标值？

例如：

α最大利润0.51200.61160.71090.8980.9821.060\begin{array}{c|c} \alpha & \text{最大利润}\\ \hline 0.5&120\\ 0.6&116\\ 0.7&109\\ 0.8&98\\ 0.9&82\\ 1.0&60 \end{array}

这比随便选一个 α\alpha 更透明。

三、所以这种情况下，λ\lambda 通常怎么出现？

对于：

max⁡f(x)\max f(x)

加上几条模糊约束，标准方法通常是固定：

α.\alpha.

写成：

μi(x)≥α.\mu_i(x)\ge\alpha.

这里的 α\alpha 是外部给定的满意度门槛，不是决策变量。

只有当研究者想让模型自己寻找“最大的共同满意度”时，才把 α\alpha 变成变量，并通常改名为 λ\lambda：

max⁡λ\max\lambda

满足：

μi(x)≥λ.\mu_i(x)\ge\lambda.

但是一旦这么做，优化目标就变成了：

让软约束满足得尽可能好。

它不再是单纯地最大化 f(x)f(x)。

因此，标准文献里要清楚区分：

α=预先规定的满意度水平\boxed{\alpha=\text{预先规定的满意度水平}}

和

λ=需要最大化的共同满意度变量\boxed{\lambda=\text{需要最大化的共同满意度变量}}

它们形式相似，但角色不同。

四、模糊目标 + 模糊约束 + 精确约束

这是你提到的第二种情况。

设：

  • 原目标不是“严格最大化”，而是一个模糊目标；

  • 有若干模糊约束；

  • 还有若干必须严格满足的精确约束。

例如：

利润希望至少达到 100 万左右；
成本最好不要超过 60 万；
工期大约不超过 30 天；
机器数量不能超过 10 台。

定义：

  • 目标满意度：

μ0(x);\mu_0(x);

  • 模糊约束满意度：

μ1(x),…,μr(x);\mu_1(x),\dots,\mu_r(x);

  • 精确约束：

gj(x)≤0.g_j(x)\le0.

这时最经典的标准模型是 Bellman–Zadeh 最大—最小模型：

max⁡λ,s.t.μ0(x)≥λ,μi(x)≥λ,i=1,…,r,gj(x)≤0,j=1,…,m,0≤λ≤1.\boxed{ \begin{aligned} \max\quad &\lambda,\\ \text{s.t.}\quad &\mu_0(x)\ge\lambda,\\ &\mu_i(x)\ge\lambda, \qquad i=1,\dots,r,\\ &g_j(x)\le0, \qquad j=1,\dots,m,\\ &0\le\lambda\le1. \end{aligned} }

这里：

  • 模糊目标参加满意度比较；

  • 模糊约束也参加满意度比较；

  • 精确约束仍然必须严格满足；

  • λ\lambda 表示所有模糊要求中最低的满意度。

精确约束不会转成：

μj(x)≥λ.\mu_j(x)\ge\lambda.

它们仍旧原样保留：

gj(x)≤0.g_j(x)\le0.

五、为什么模糊目标和模糊约束能放在一起？

在模糊决策理论中，模糊目标和模糊约束本质上都被看成对方案 xx 的模糊集合。

模糊目标：

G={x:μG(x)}.G=\{x:\mu_G(x)\}.

模糊约束：

Ci={x:μCi(x)}.C_i=\{x:\mu_{C_i}(x)\}.

一个方案既要属于目标集合，也要属于所有约束集合，因此决策集合取交集：

D=G∩C1∩⋯∩Cr.D=G\cap C_1\cap\cdots\cap C_r.

在最经典的模糊集合交运算中：

μD(x)=min⁡{μG(x),μC1(x),…,μCr(x)}.\mu_D(x) = \min \{ \mu_G(x), \mu_{C_1}(x), \dots, \mu_{C_r}(x) \}.

所以选择最佳决策就是：

max⁡xμD(x)=max⁡xmin⁡{μG(x),μC1(x),… }.\max_x\mu_D(x) = \max_x \min \{ \mu_G(x), \mu_{C_1}(x), \dots \}.

引入 λ\lambda 后就得到前面的模型。

所以在这个标准模型中：

λ\lambda

确实是整体满意度，而不是某一条单独约束的满意度。

六、模糊目标不一定必须和模糊约束使用同一个 λ\lambda

Bellman–Zadeh 模型只是最经典、最朴素的模型，它默认所有模糊要求同等重要。

现实中还经常采用其他形式。

1. 目标满意度最大，约束设置底线

例如：

max⁡μ0(x),s.t.μi(x)≥αi,gj(x)≤0.\boxed{ \begin{aligned} \max\quad &\mu_0(x),\\ \text{s.t.}\quad &\mu_i(x)\ge\alpha_i,\\ &g_j(x)\le0. \end{aligned} }

含义是：

模糊约束至少满足到规定水平，然后让模糊目标尽可能满意。

这与普通的“最大化目标、满足约束”结构最接近。

2. 不同模糊要求设置不同门槛

μ1(x)≥0.9,\mu_1(x)\ge0.9, μ2(x)≥0.7,\mu_2(x)\ge0.7, μ3(x)≥0.5.\mu_3(x)\ge0.5.

因为不同要求的重要性和容忍度可能不同。

3. 加权满意度

max⁡∑i=0rwiμi(x).\max \sum_{i=0}^{r}w_i\mu_i(x).

这样允许某些满意度降低，由其他满意度提高来补偿。

而 max–min 模型：

max⁡min⁡iμi(x)\max\min_i\mu_i(x)

基本不允许这种补偿，它主要保护“最差的一项”。

七、把你提到的两类问题标准化

情形 A：目标精确，部分约束模糊，部分约束精确

最标准的写法之一是：

max⁡f(x),s.t.μi(x)≥αi,i=1,…,r,gj(x)≤0,j=1,…,m.\boxed{ \begin{aligned} \max\quad &f(x),\\ \text{s.t.}\quad &\mu_i(x)\ge\alpha_i, \qquad i=1,\dots,r,\\ &g_j(x)\le0, \qquad j=1,\dots,m. \end{aligned} }

这时通常：

  • 不最大化 λ\lambda；

  • 不需要引入 λ\lambda；

  • 直接规定每条模糊约束最低可接受满意度。

如果满意度门槛不知道，就把问题作为多目标问题处理，或者扫描 α\alpha。

情形 B：目标模糊，部分约束模糊，部分约束精确

经典 max–min 模型：

max⁡λ,s.t.μ目标(x)≥λ,μ模糊约束,i(x)≥λ,gj(x)≤0.\boxed{ \begin{aligned} \max\quad &\lambda,\\ \text{s.t.}\quad &\mu_{\text{目标}}(x)\ge\lambda,\\ &\mu_{\text{模糊约束},i}(x)\ge\lambda,\\ &g_j(x)\le0. \end{aligned} }

或者采用目标—约束分离模型：

max⁡μ目标(x),s.t.μ模糊约束,i(x)≥αi,gj(x)≤0.\boxed{ \begin{aligned} \max\quad &\mu_{\text{目标}}(x),\\ \text{s.t.}\quad &\mu_{\text{模糊约束},i}(x)\ge\alpha_i,\\ &g_j(x)\le0. \end{aligned} }

选择哪一种，不是数学自动决定的，而取决于决策者的偏好：

  • 是否把目标和约束视为同等地位；

  • 是否优先保证最差满意度；

  • 是否允许不同要求相互补偿；

  • 是否有明确的最低满意度标准。

八、最准确的总图

模糊规划并不存在一个唯一的万能模型。

标准建模顺序是：

先确定哪些是硬约束、哪些是软要求\boxed{ \text{先确定哪些是硬约束、哪些是软要求} }

然后：

为软要求定义隶属度函数\boxed{ \text{为软要求定义隶属度函数} }

接着选择决策规则：

已知最低满意度

μi(x)≥αi,\mu_i(x)\ge\alpha_i,

然后优化原来的精确目标。

希望最差满意度尽可能高

max⁡λ,μi(x)≥λ.\max\lambda, \qquad \mu_i(x)\ge\lambda.

同时关心原目标和满意度

建成多目标规划，求 Pareto 解。

目标本身也是模糊愿望

把目标也写成满意度，再采用 max–min、加权和或目标—约束分离方法。

所以最容易记住的一句话是：

λ 不是模糊规划的固定组成部分，而只是 max–min 模型的辅助变量。\boxed{ \lambda\text{ 不是模糊规划的固定组成部分，而只是 max–min 模型的辅助变量。} }

你说的“精确目标加少数模糊约束”，标准处理通常不是最大化 λ\lambda，而是先选定满意度水平 α\alpha，再在相应的 α\alpha-截集可行域上最大化精确目标。
