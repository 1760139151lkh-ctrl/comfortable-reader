第三章　经典方法从哪里来，又不该被说成什么

数学模型的来源和模型本身同样重要。一个方法可以很经典，却不意味着它适用于所有问题；一个参数化选择可以很方便，却不意味着它是数学必然。

讲到“经典方法”时，必须把来源、适用范围和建模选择分开。下面不把任何路线冒充成唯一标准，而是说明这些说法分别从哪条理论脉络发展出来。

而且你质疑得对：我把“标准做法”“通常做法”说得太满了。更准确的说法应该是：

这是模糊规划文献中的几类经典建模路线，不是全领域唯一公认的统一标准。

这些说法分别从哪里来？

1. 模糊目标、模糊约束统一成满意度：Bellman–Zadeh

最源头的是：

R. E. Bellman 与 L. A. Zadeh，1970，
“Decision-Making in a Fuzzy Environment”

这篇文章明确提出：

  • 目标和约束都可以是模糊集合；

  • 模糊决策可以看成目标集合与约束集合的交集；

  • 最优决策取该决策模糊集合隶属度最大的点。PubsOnline

也就是：

D=G∩C1∩⋯∩Cm.D=G\cap C_1\cap\cdots\cap C_m.

若采用最小算子表达交集：

μD(x)=min⁡{μG(x),μC1(x),…,μCm(x)},\mu_D(x) = \min\{\mu_G(x),\mu_{C_1}(x),\dots,\mu_{C_m}(x)\},

那么就是：

max⁡xmin⁡iμi(x).\max_x\min_i\mu_i(x).

引入 λ\lambda：

max⁡λ,s.t.μi(x)≥λ,\begin{aligned} \max\quad &\lambda,\\ \text{s.t.}\quad&\mu_i(x)\ge\lambda, \end{aligned}

只是对这个 max–min 问题的普通辅助变量改写。

所以，“模糊目标与模糊约束统一放进 λ\lambda”的来源主要是这条 Bellman–Zadeh 路线，不是所有模糊规划都必须这样做。

2. 把它做成线性规划：Zimmermann

接下来最重要的是：

H.-J. Zimmermann，1978，
“Fuzzy Programming and Linear Programming with Several Objective Functions”

Zimmermann 将 Bellman–Zadeh 的模糊决策方法用于线性规划和多目标线性规划。之后的 Springer 教材对这段历史的概括是：Zimmermann 考察了带模糊目标与模糊约束的线性规划，并通过线性隶属度函数得到等价的普通线性规划。Springer Link+1

例如：

ai⊤x≲bia_i^\top x\lesssim b_i

具有线性容忍范围 pip_i，其满意度写成：

μi(x)=1−ai⊤x−bipi.\mu_i(x) = 1-\frac{a_i^\top x-b_i}{p_i}.

令：

μi(x)≥λ,\mu_i(x)\ge\lambda,

就得到：

ai⊤x≤bi+pi(1−λ).a_i^\top x \le b_i+p_i(1-\lambda).

因此我前面所讲的“最大化最低满意度 λ\lambda”主要来自 Zimmermann 型模糊线性规划，不应笼统地说成整个模糊规划的唯一标准。

Zimmermann 还写过：

Fuzzy Set Theory—and Its Applications

其中第四版的“Decision Making in Fuzzy Environments”一章位于第 329–370 页，随后还有工程与管理应用章节。Springer Link

3. 精确目标 + 软约束：Verdegay、Chanas、Rommelfanger–Słowiński

你提出的那种：

max⁡f(x)\max f(x)

其中 f(x)f(x) 是精确目标，只有若干约束是软的或模糊的，确实是文献中单独研究的一类问题。

比较直接的早期来源是：

J. L. Verdegay，1982，
“Fuzzy Mathematical Programming”

他的处理是考察约束模糊集合和目标模糊集合的不同 α\alpha-截集；对于每个给定的 α\alpha，得到一个普通的确定性数学规划问题。ResearchGate+1

若目标是精确的、约束是模糊的，就可以形成一族参数规划：

max⁡f(x),s.t.μi(x)≥α,x∈X,\begin{aligned} \max\quad &f(x),\\ \text{s.t.}\quad&\mu_i(x)\ge\alpha,\\ &x\in X, \end{aligned}

其中 α\alpha 是给定参数。

S. Chanas 在 1983 年的论文：

“The Use of Parametric Programming in Fuzzy Linear Programming”

进一步研究了这种参数规划路线。科学直通车

后来的权威综述章节：

H. Rommelfanger 与 R. Słowiński，1998，
“Fuzzy Linear Programming with Single or Multiple Objective Functions”

一开始就把最简单的“具有软约束的线性规划”称为 flexible programming，然后再分别讨论模糊数据、模糊目标、多目标折中以及不同的模糊不等式语义。Springer Link

因此，我前面说：

对于精确目标与软约束，可以固定一个满意度水平 α\alpha，再最大化精确目标。

这不是凭空编的；它对应 Verdegay–Chanas 的参数化路线，以及后来手册里所说的 flexible programming。但我不该把它说成“正常人唯一都会这样做”。

哪本书最直接回答你现在的问题？

最贴近“模糊规划到底有哪些不同模型”的一本是：

Young-Jou Lai、Ching-Lai Hwang，
Fuzzy Mathematical Programming: Methods and Applications，Springer，1992。

这本书专门系统整理和分类模糊数学规划与可能性规划方法，其中“Fuzzy Mathematical Programming”主体章节是第 74–186 页。出版方也明确说，它的目标就是系统综述和分类已有方法及其适用范围。Springer Link

另外两本/章也值得对照：

  • Masatoshi Sakawa，Fuzzy Sets and Interactive Multiobjective Optimization，1993：第 36–90 页专讲模糊线性规划。Springer Link

  • Roman Słowiński 编，Fuzzy Sets in Decision Analysis, Operations Research and Statistics，1998：其中 Rommelfanger–Słowiński 一章第 179–213 页专门区分软约束、模糊目标和单目标/多目标问题。Springer Link+1

我刚才真正应该怎样表述？

我应该说：

  1. Bellman–Zadeh/Zimmermann 方法是经典的 max–min 满意度方法；

  2. 固定 α\alpha 后优化精确目标是模糊约束问题的一种经典参数化处理；

  3. 模糊目标、软约束、模糊系数、可能性约束不是同一种问题；

  4. 不存在一个无条件适用于所有“模糊规划”的唯一模型；

  5. 选择哪种模型，必须先说明“模糊”到底表示软偏好、容忍违反，还是参数本身不精确。

所以你刚才对“所谓标准”的警惕是对的。可以称 Bellman–Zadeh 与 Zimmermann 方法为经典方法，但不能不加限定地把它叫作唯一标准方法。
