十一、到这里，才讨论各个学科应该摆在哪里

现在完整流程已经闭环，我们再把各个学科放进去，就不会突然跳层。

整体地图是：

│
├─ 任务识别

│
├─ 结构抽象
│  ├─ 连续 / 离散
│  ├─ 静态 / 动态
│  ├─ 确定 / 随机
│  ├─ 单主体 / 多主体
│  ├─ 网络 / 空间
│  └─ 单阶段 / 多阶段
│
├─ 模型建立
│  ├─ 统计模型
│  ├─ 机器学习模型
│  ├─ 微分方程模型
│  ├─ 图与网络模型
│  ├─ 数学规划模型
│  ├─ 随机过程模型
│  ├─ 博弈模型
│  ├─ 控制与MDP模型
│  └─ 仿真模型
│
├─ 数据与参数
│  ├─ 数据清洗

各学科的地位可以这样理解。

数学建模

不是其中一个局部模块，而是：

从现实问题到现实结论的整个过程

它是总流程。

概率论

是不确定性的基础数学语言，主要进入：

  • 随机结构；
  • 随机模型；
  • 参数分布；
  • 风险分析；
  • 随机仿真。

统计学

主要位于：

数据→参数、规律与不确定性

负责：

  • 描述数据；
  • 参数估计；
  • 假设检验；
  • 回归；
  • 预测；
  • 置信区间。

机器学习

主要位于：

数据→预测、分类和近似

也可以辅助：

  • 优化算法；
  • 动态规划；
  • 仿真；
  • 控制策略。

微分方程与动力系统

主要位于：

机理描述与动态演化

回答系统如何随时间变化。

图论

主要位于：

关系结构的数学表达

图算法和网络优化则进入求解层。

运筹学

主要覆盖：

系统分析+优化决策+资源配置+运行管理

它横跨：

  • 模型层：数学规划、组合优化、排队、库存；
  • 求解层：优化算法、动态规划、网络算法；
  • 决策层：把结果转化成行动。

最优化理论

主要研究：

  • 最优解存在性；
  • 凸性；
  • 对偶；
  • KKT 条件；
  • 算法收敛；
  • 最优性条件。

它位于模型结构与求解算法之间。

数值分析

主要位于计算层，研究：

  • 离散化；
  • 误差；
  • 稳定性；
  • 收敛性；
  • 数值求解。

控制理论

主要位于：

动态系统中的反馈决策

它连接：

  • 微分方程；
  • 动态规划；
  • 优化；
  • 状态估计；
  • 实时决策。

博弈论

主要位于：

多个理性主体相互影响的决策

它不是普通单目标优化的简单延伸，因为每个主体的目标不同。

计算机科学

主要支撑：

  • 算法复杂度；
  • 数据结构；
  • 高效实现；
  • 并行计算；
  • 软件系统；
  • 大规模计算。

仿真

主要承担：

在虚拟环境中实验系统和方案

它既可以是模型，也可以是求解、评估和验证工具。
