12. 协方差：高维指标为什么可以被压缩？

PCA 和因子分析之所以能把很多指标压缩为少数方向，前提是指标之间存在共同变化。描述这种共同变化的核心对象就是协方差矩阵。

设标准化或至少中心化后的数据矩阵为：

Z∈Rm×n.

每一行是一个对象，每一列是一个指标。中心化意味着每一列均值为 0。样本协方差矩阵为：

S=1m−1ZTZ.

12.1 为什么 ZTZ 会产生协方差？

矩阵第 j 列记为 zj，第 k 列记为 zk。则：

(ZTZ)jk=zjTzk=∑i=1mzijzik.

因为两列已经中心化，除以 m−1 后正是样本协方差：

sjk=1m−1∑i=1mzijzik.

当两个指标经常同号偏离均值，乘积多为正，协方差为正；一个高于均值时另一个常低于均值，乘积多为负，协方差为负。

对角元素是方差：

sjj=1m−1‖zj‖2.

若每列进一步除以标准差，则 S 变成相关系数矩阵。

12.2 协方差矩阵为什么不会有负特征值？

对任意向量 a∈Rn：

aTSa=1m−1aTZTZa=1m−1‖Za‖2≥0.

因此 S 是半正定矩阵，特征值均不小于 0。更直观地说，Za 是沿方向 a 合成出来的一列新变量，上式正是它的方差，方差当然不能为负。

这条等式也直接引出 PCA：寻找单位方向 a，让投影方差 aTSa 最大。

12.3 协方差为零不等于独立

协方差只衡量线性共同变化。若随机变量 Y=X2，且 X 关于 0 对称，则 X 与 Y 明显依赖，但可能有 Cov(X,Y)=0。只有在特定条件下，例如联合正态，零协方差才蕴含独立。

因此，PCA 和普通因子分析主要捕捉线性结构。复杂的弯曲结构可能需要核 PCA、非线性因子模型或投影寻踪等工具。
