# C10 观察同表、干预异果：运行前固定的两个教学世界

**身份与目的。**下列数据由作者明确给出的随机机制生成，是用来证明“仅有 \(P(X,Y)\) 不一定能推出干预效果”的**教学构造**，不冒充医疗、商业或社会中的真实试验。与第九章批发客户档案没有任何变量继承；本机程序用 Python 标准库先精确穷举，再做一次有随机波动的演示运行。

**共同基础。**所有噪声为独立的二值随机量，\(U\sim\mathrm{Bernoulli}(1/2)\)，\(N_X,N_Y\sim\mathrm{Bernoulli}(0.1)\)。符号 \(\oplus\) 表示异或。世界 A 的结构为 \(X=U\oplus N_X,\ Y=U\oplus N_Y\)：\(U\) 同时影响两项可见量，强制改 \(X\) 不改变 \(Y\) 的方程。世界 B 保留 \(X=U\oplus N_X\)，另取与其他量独立的 \(N_B\sim\mathrm{Bernoulli}(0.18)\)，令 \(Y=X\oplus N_B\)：\(U\) 通过 \(X\) 影响 \(Y\)，强制改 \(X\) 会改变 \(Y\) 的分布。\(.18=2(.1)(.9)\) 是在运行前选定，以使两世界观察表一致；不是拟合了运行结果才调出的值。

**预先推到的精确数。**按各自所有外生变量穷举，两个世界的 \(P(X=x,Y=y)\) 都应为行 \(x=0,1\)、列 \(y=0,1\) 的 \(\begin{pmatrix}.41&.09\\.09&.41\end{pmatrix}\)。两世界从观察表读到的 \(P(Y=1\mid X=1)-P(Y=1\mid X=0)=.82-.18=.64\)。干预另算：把 \(X\) 原方程替换成常数 \(x\)，其余方程和外生分布保持；世界 A 在 \(do(X=0)\) 和 \(do(X=1)\) 下 \(E[Y]\) 都为 .5，效果 0；世界 B 分别为 .18、.82，平均效果 .64。程序逐项 assert 这些精确值。两表相同的论断只针对**仅观察 X,Y**；若 U 可测或可随机改变 X，信息身份便不同。

**潜在结果与调整。**在同一组外生值上分别替换 \(X=0,1\)，得到 \(Y_i(0),Y_i(1)\)。世界 A 的两者相同，世界 B 由同一个 \(N_B\) 生成且平均差为 .64。若实验者记录 U，两个世界都满足每个 \(U=u\) 下处理两种 \(X\) 值有正机会；可从观察条件表计算 \(\sum_u P(Y=1\mid X=x,U=u)P(U=u)\)，与各自精确干预答案核对。这样只在**已写出的模型条件**下展示调整，不拿“控制了一个变量”当普遍因果许可证。

**一次有限样本演示。**在每个世界用固定种子 20260924 各模拟 20,000 个单位。每单位先从该世界外生变量得到观察 \(X,Y\)，另独立抽一次公平随机分配 \(A\)，把同一单位的 \(X\) 方程换为 \(A\)，得到该单位在随机分配下的结果。报告观察组差与随机分配组差及两组人数；这只是与上面精确数学对照的单次 Monte Carlo 示意，数值不强求恰好等于 0 或 .64，也不以一轮“显著性”声称任何现实效应。固定外生值用来计算两项潜在结果，是电脑知道教学世界内部的特权，不等于真实实验能同时观察同一个人的两种结果。

**边界变更。**删去 \(U\) 与 \(Y\) 的共同原因关系会改变世界 A；让 \(N_X=0\) 会破坏给定 \(U\) 下两种 \(X\) 都可出现的重叠；把 \(Y=X\) 改为 \(Y=X\oplus N_B\) 之外的机制可改变干预效果。教材练习可改这些真实条件再运行，但任何新分布都须重算观察表，不能沿用本协议的 .41/.09 或把一个证明失效直接写成原结论必假。
