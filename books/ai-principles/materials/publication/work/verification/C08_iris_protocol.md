# C08 鸢尾花比较：看分数之前定下的任务

**资料与问题。**只读 UCI Iris 原 ZIP 中的 iris.data；两个文件的 SHA-256 见 work/data/uci_iris_SOURCE.md。原表是 150 株已记录类别的花。本次另设一个二类教学任务：只看其中 versicolor 与 virginica 共 100 行，用每株的**花瓣长度、花瓣宽度**（原文件第 3、4 列，厘米）预测这两个名字之一。选择这对类别，是因为 Fisher 1936 年原文已指出它们的合成测量有重叠；选择两项花瓣测量，便于把规则画在同一平面。它们是作者从公开资料和史料中事先选择的，不能把这次留出分数称为未经任何先验选择的未来发现。原论文先研究 setosa 与 versicolor 的四项测量，绝非本实验的原作者方案。

**单位与切分。**每行必须有四个有限数和三个允许类别之一，三类各 50 行。仅保留目标两类，标签记 versicolor=-1、virginica=+1。按**四项原测量完全相同**分组；不把同一组分到两边。相同数值不证明同一株花，只把身份不明的重复项保守地放在一起。每个类别内将各组按其最早原文件行号排序，**每类重新建立** Python 的 random.Random(20260923) 洗牌；按样本数依次填训练 30、验证 10、测试 10，某组放不下当前段就先试下一段，单项组再填余下空位。两个类别各自完成后合并成每段 60、20、20 行；若这个确定性规则无法达到这些数，程序停止，不临时挪动标签让结果更好看。公开文件的原行号和最终切分保存到结果中。

**预处理。**只用训练 60 行求两项输入的平均值与标准差，按 \((x-\mu)/s\) 缩放三段；两项标准差若有零则停止。测试行的值不能影响 \(\mu,s\)。六条办法接收同一对已缩放的输入与相同训练标签。

**事先固定的六条办法，顺序也用于验证平手。**

1. Fisher 式二类线性判别：从训练行的两类均值和类内散布矩阵求方向 \(S_W^{-1}(\mu_+-\mu_-)\)，阈值取两类投影均值的中点。若矩阵不可逆则停止，不事后补正则化。
2. 五近邻：按标准化后的欧氏距离取最近五个训练行，取多数标签；距离相同按原行号决定入选顺序。
3. 单棵二叉树：Gini 分割，最大深度 2，随机状态 20260923。
4. 线性支持向量机：scikit-learn SVC，kernel=linear，C=1。
5. 高斯核支持向量机：SVC，kernel=rbf，C=1，gamma=1；这里 \(\exp(-\|x-z\|^2)\) 的距离在训练期标准化后的坐标中计算。
6. 随机森林：100 棵 Gini 树，bootstrap=True，max_depth=2，每次分割最多考虑 1 项输入，random_state=20260923。

不根据验证结果另调 \(k\)、树深、C、gamma 或森林棵数；这六条是为说明预测怎样组织而定的课堂比较，并非给每种算法做最大预算调参比赛。包的当前本机版本为 Python 3.13、NumPy 2.4.6、scikit-learn 1.9.0，具体代码按本机可执行接口核对。

**评分和信息顺序。**每段对每条规则记录错分株数、错分率及两类各自的错分；验证段错分株数最少的规则为本次选择，平手按上列先后。训练、验证和测试沿同一固定切分；验证选择完成后，才计算测试段的六条已定规则并公布全部数字。不得见测试成绩后改特征、候选或切分，再把同一测试段称作首次独立检验。可展示一株验证花怎样被六种规则分别判断，但不能拿这株反复调整六个办法。

**能说明与不能说明。**这是已公开近九十年的极小标本表，原论文与 UCI 页面已经告诉我们某些类别是否易分；1988 年 UCI 版本还与 1936 年表格有两行已知差异。本机留出段可检查程序和此表上的比较，不代表新的野外地点、采集年份、未见种群，也不能直接与 Fisher 原论文当年四测量三物种的数字并列。方法差异解释完，花的例子退出主线。
