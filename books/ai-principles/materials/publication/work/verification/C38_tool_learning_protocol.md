# C38工具请求、真实返回与可学习回答：本机执行范围

本章基线是C19从随机参数训出的4,930,304参WikiText模型，再由C25本书的Dolly短指令混合旧资料支适配。实际父文件`work/runs/c25_full_mix_trial/best.pt` SHA `a6f4c6fa030b4099ca39a7e99855f35303fa48406fb5adae7d1c82a06855cced`，C18固定8192项分词器SHA `5371bf7ee34002268dabc1676045314ef327d7d7e6c75c15a868b0a531a60cf4`。没有外部强模型生成成功样本，也没有用用户本人反馈。工具主流程代码为`work/code/c38_tool_data.py`/`c38_tool_data_v3.py`、`c38_tool_train.py`、`c38_tool_evaluate.py`、`c38_copy_gate.py`；资料细节见[v1源卡](../data/c38_tool_trajectories_v1/SOURCE.md)和[v3源卡](../data/c38_tool_trajectories_v3/SOURCE.md)。

## 问题、答案与谁写每一段

训练/验证/测试都用同一短任务定义：在`Q:`读用户问句，模型在`A:`后可自由输出一行直接答案或`call mul(a,b)`/`call title(id)`；模型真的输出合法调用后，本机宿主才用Python整数算10—99乘法或在C18真实训练文章标题表中按作者文章编号读值，并把`T:`行插入，再由模型在第二条`A:`后自由答。`mul`和`title`是**两种明确允许的纯只读操作**，不调用shell或任意Python字符串求值，不发送外部网络请求。未经模型产生的字符串，宿主绝不补造调用；无效名/参数被记失败，必要时有限返回`NOT_FOUND`。直接题由模型不调用地答。当前实现最多一条调用和一个返回，不等于搜索未知API、多工具规划、任何远程副作用。

资料共916/167/167条v1完整题：乘法600/100/100组按完整有序数对分开；真标题190/40/40按C18文章编号分开；直接词56/12/12按(词,模板)组合分开；缺席标题编号70/15/15按整数ID分开。标题原内容来自WikiText训练文章，故C19预训练可能见过文字，**但未被本章训练代码看到内部留出问题/答案**。乘法数的因子、直接词、模板跨组可能重现，不能声称未见语法/未见运算；完整题组合与标题ID不跨组。数据准备程序曾读取全原文章索引来生成物理分组，训练器只打开`train.jsonl`/`validation.jsonl`和哈希清单，不打开`test.jsonl`。

每个轨迹段单独分词，再接BOS和C19 128位模型输入；v3最长训练/验证/测试真实输入85/85/81位。目标向左错一位：位置`i`的输出猜位置`i+1`。本书主要SFT只让模型第一条A动作与工具后的第二条A回答（含结尾换行）进入交叉熵，Q和T虽然**对后续位置可见**，但自身目标位是`-100`。这是一种为教“模型负责写的内容”选择的监督目标，**不是**Toolformer原论文的方法：Toolformer把采样、执行、按后续NLL筛过的调用/结果插回全文，随后用普通全文LM目标微调。`work/results/c38_loss_source_probe.json`在一条真实训练标题轨迹上，助手位11目标NLL0.26956，整段67目标NLL7.45718，输出头梯度余弦0.1900/差范数3.258；只是两个合法目标确实改变导数的单例核算，不给其余任务排名。

## 在测试未开时如何修一个真实失败

同一C25父权重在验证自由167题整题0对；v1全参数行动/回答SFT，每批四类各6道、AdamW、验证四类NLL等权平均选1800步，验证整题68/167。乘法动作参数正确94/100但整题43/100，真标题参数35/40却整题0/40；直接10/12、缺席15/15。`work/results/c38_tool_validation_free_1800.json`保留真实逐项输出，如91×26模型写`call mul(91,26)`，工具真返2366，模型却答266。这个结果阻止“会调用=会利用观察”的偷换。

v2只改训练来源：原190个训练标题ID各添6个作者模拟的目录版本，另添1000条数字复制练习；验证/测试JSONL均与v1**逐字节相同**。模拟目录版本的返回值只从v1训练标题选，不冒充真实WikiText标题变更。按验证选2400步，验证整题100/167，乘法79/100但标题仍0/40、直接6/12。另将最终答案目标的训练权重乘4，同资料同2400步计划验证整题73/167，标题仍0/40，故“多训练/增答复loss”不是已证明的修法。这些都是验证上的公开返工，不是另一份独立测试。

分词进一步暴露有实质差别：v1/v2工具返回的首词在`T: Weather buoy`里含前导空格BPE片段`ĠWe`，原段`A: `后单独分词的目标`Weather buoy`却起为`W,e,...`。v3把`A:`后那一个空格归**助手生成**，故观察值和回答的值/换行编号可逐位置对应；源码对190条训练标题逐条核BPE ID。它仍使用v1的验证/测试题字节，训练保留1140模拟目录版本、重复224个直接词例并加200数字复制例。v3行动模型按宏验证NLL选2200步，文件SHA `e000f24e5422fc5a0d2e1712b50229b8b1425930c9e154ac345eb85f8226a95d`；验证自由仍只有100/167、真标题0/40。**修输入表示是必要的对齐动作之一，这次并不足以让小模型自然学会复制未见标题。**

于是作者给固定的v3行动模型另接一个可检查的复制选择器，总共**195**个新参数（193项线性权重、一偏置、一距离参数）。宿主明示工具返回值的token区间、回答第几个token和`found`状态。候选复制分布对观测位置`j`和当前回答序号`r`用`softmax_j[-λ|j-r|]`，相同编号的候选概率相加；一层sigmoid门由**冻结模型的当前位置活动与found位**算`g_t`，最后

\[
p(v)=(1-g_t)p_{\rm vocab}(v)+g_t\sum_{j\in\text{返回值}}\alpha_{t,j}\mathbf1[x_j=v].
\]

距序号近的源位先占较大权重，`λ=softplus(raw_scale)>0`由这195参数中的一项控制；门决定本次从原词表还是源值取。训练时原四层、行动产生器**冻结**，只在训练标题/乘法/缺席工具题的最后答复位置优化门与距离，直接题与动作仍由原模型处理。这个结构大幅增加了“照返回复制”的先验知识，且依赖宿主给准确来源位置；不冒称C19自发学会证据定位或复杂语义推理。`work/runs/c38_copy_gate_400/train.json`记录只读训练/验证、400步选择，验证最后答复三类宏NLL降至0.03511；同167道验证自由任务149对（乘法93/100、标题31/40、直接11/12、缺席14/15）。原v3不带复制门只有100/167，这是**额外结构与宿主标注条件改变**的对照，非单纯多训400步的公平归因。

为区分“记住题号”与“读了返回”，在测试未开时固定这份模型和门，仅用验证中12个正确乘法调用及12个正确标题调用。前者把真实积故意改为积+1，后者把真标题换另一条训练标题；24项正常与24项改值后的最终回答都照被提供的值输出，见`work/results/c38_observation_validation_intervention.json`。故意错误乘积**不是正确数学答案**，恰说明用观察≠工具值可信/最终任务正确。这项有限干预不证明任意长度/语言/网页返回都会被准确读出。

## 可复核与后续身份

所用程序可在同一台机器直接运行，另指定新目录/文件可重训：

~~~powershell
Set-Location '.'
python work/code/c38_tool_train.py --data-dir work/data/c38_tool_trajectories_v3 --out-dir work/runs/c38_my_action --steps 2400 --lr 0.0002 --validate-every 100 --per-kind 6
python work/code/c38_copy_gate.py --action-checkpoint work/runs/c38_my_action/best.pt --out-dir work/runs/c38_my_copy_gate --steps 400 --lr 0.01 --validate-every 20
python work/code/c38_tool_evaluate.py --split validation --data-dir work/data/c38_tool_trajectories_v3 --checkpoint work/runs/c38_my_action/best.pt --copy-gate work/runs/c38_my_copy_gate/copy_gate.pt --out work/runs/c38_my_validation.json
~~~

读者若再对同`test.jsonl`运行，只是**已打开内部测试的复核**，不是新的独立留出。复制门所在源文件后加了`--action-checkpoint`选项以便读者使用自己重训的权重；其数学/已选原权重未改，并以2步新目录做了CLI smoke。行动支的训练报告约61秒/峰CUDA约541MiB；复制门报告从预抽冻结模型活动到选择结束约3.7秒，含模块导入和加载的完整进程本次约10秒，均为本机条件；小数据轻量可跑不等于通用Agent容易训练。所有历史论文的模型/资料和可执行任务不同，未复刻WebGPT/TALM/ReAct/Toolformer/API-Bank/τ-bench的成绩。作者审读/本地结构发布不证明读者掌握或用户验收。
