# 六类物体是否在图里的中间练习

本机另从已下载、CRC已验的 COCO 官方 `annotations_trainval2017.zip` 中仅取 `instances_val2017.json`，36781个实例标注、80个类别；原 JSON 的SHA和逐图内部划分在 `manifest.json`。这不需要再次下载或改造原照片。照片逐张 Flickr 权利仍以 `coco2017_val_c35/SOURCE.md` 为准，标注受 COCO 官方 CC BY4 条款。

作者查看各类正例数量后**事后选择** person、car、bottle、cup、chair、dining table 六个常见类别；不称事先盲选。对每个类别，在C35原4000/500/500整图切分内，把“有这类COCO实例标注”的图和“没有这类标注”的图各取相同数，组成固定英文问句 `Is there a ... in this picture?`、答案 yes/no。训练/验证/留出问题数7388/1002/990，每类恰好一半yes，使只按这六个问题背常见答案的规则最多50%。完全相同的真实原照片可为不同类别承担不同问句；整张图从未跨训练和验证/留出组。详细逐类行数及提取程序见 `manifest.json` 与 `work/code/prepare_c35_object_questions.py`。

这是一条**用真实照片和真实对象标注造的窄课程**，不是VQA人提出的开放自然问答。把“未见此类标注”作no依赖COCO注释覆盖，极小、被遮住或漏标的物体可能真实存在；不凭这套标签声称机器懂“柜门后面是哪根管”。若相同问题换图片、模型答案应改变，这个实验能检验可训练图像表示和问题类别如何共同作用；它不能抵扣上文26333个人写VQA问题和十人答案的困难。
