# 第三十章二值服饰图来源

从第十三章已下载并核对的[Zalando Fashion-MNIST 官方商品图](../fashion_mnist/SOURCE.md)派生，不新增人工类别或图片。原始每个灰度像素为0—255整数；脚本 work/code/prepare_c30_fashion_binary.py 固定把 **原值≥128 变1，<128变0**，保留28×28位置。当前派生资料共50,000张训练图与10,000张验证图，逐数组 NPY 字节SHA、前景比例及原件身份在[清单](manifest.json)。原C13切分曾按类别分层；本脚本本身只读原图像包和已存行号、不打开任何类别标签。不能把整段准备历史改写成“完全未借过类别”。

二值化是本章为明确 Bernoulli 像素概率而做的建模选择：随机变量现在是每格0或1，已失去原灰度深浅与部分质地。后文VAE对二值图计算的逐像素Bernoulli对数似然和自回归NLL，不能冒充原灰度商品图的概率，也不能与C29原图对比模型的训练loss直接排名。原官方测试包并未在本脚本派生；但这套官方测试在C13/C29早已被作者看过，未来即使另开也不再是本任务的首次盲测。
