# C33 真实多帧动作来源：Penn Action

- [宾夕法尼亚大学 Penn Action 官方说明](https://dreamdragon.github.io/PennAction/)及同页大学服务器的 `Penn_Action.tar.gz`，本机归档 3235203923 字节、SHA-256 `e3e41bd99deb7b3beb9785f78b209de272bb0fa60ff4432ffa88118907a797de`，完整遍历归档得到2326份 `.mat` 标注、163841张 `.jpg` 真RGB帧。来源/成员数与原文件保存在`manifest.json`；`extract_penn_action.py`只在工作区安全解出`frames/`和`labels/`常规文件，路径包含性和每项大小核查，原归档不改。
- 实际安全提取后的`extraction_manifest.json`确认163841帧/2326标注共3454585414未压缩字节；`inventory.json`逐序列核标注帧数与JPG数，无不匹配，官方标记`train=1`共1258段、`train=-1`共1068段，15个动作类。首段棒球投球的第1/75/151帧已直接目视，确实是同一现实场景的不同姿势，未以作者手绘帧代替。测试标记在清单阶段只计来源/数量，模型选择不使用其帧或动作、关节数值。
- [原作者2013 ICCV论文](https://dreamdragon.github.io/papers/iccv13_acteme.pdf)§4—5：这是来自YouTube等的非脚本化人类动作片段，15类，逐帧13个头、肩、肘、腕、髋、膝、踝点的位置/可见性；人工标注每段由三份独立标注经异常剔除和平均合成。官网 `.mat` 还含粗视角、逐帧框和官方训练/测试标记。原文说训练/测试约各半，同一原长视频的片段不跨组；本书尊重官方组别，若从其训练组另取验证，必须仍按原序列身份分。
- 这些是图像平面上的**像素坐标**，不是已知三维关节或地面上的真实速度。官方页面/归档说明没有给每帧可靠统一的实秒时间戳或逐视频帧率；当前只承诺“隔几帧的像素位移”，不把它凭空换算成米/秒。相机运动、视角和遮挡都可改变像素轨迹；可见性标记先于坐标差使用。
- 官网和归档目前未找到明确的数据再使用许可文本；归档中三个非JPG/MAT普通文件只有`README`和两份MATLAB可视化脚本，没有许可证。用途限本机学习/研究，不将原帧或衍生可识别图像公开上传/发布；许可状态在这里记为 `UNKNOWN`，不得依据他站猜成CC许可。之后若需对外发行书中包含的视频帧或训练衍生资料，先另核权限。当前只在包内`work/`执行读取、训练和本地读者入口。
- 用户要求真实多帧，不由作者手绘球轨迹冒充本资料。若后续把关节位移符号、时间顺序正反或下一帧像素作为**本书另造目标**，标注来源与原Penn动作类别分开，所有派生窗口按原视频保持同组；官方测试先封存，模型/阈值只在训练/验证决定。
