# C35 外部已训练 CLIP 对照

- 代码来自 [OpenAI 官方 CLIP 仓库](https://github.com/openai/CLIP)，本机 `pip` 安装时解析 commit `d05afc436d78f1c48dc0dbf8e5980a9d471f35f6`，独立环境 `work/envs/c35-clip`。官方 API `clip.load('ViT-B/32')` 提供图像224像素预处理/自有分词器，非本章112像素卷积/30词小模型的相同架构。
- 官方权重从 `https://openaipublic.azureedge.net/clip/models/40d365715913c9da98579312b702a82c18be219cc2a73407c4526f58eba950af/ViT-B-32.pt` 获得，文件353976522字节，SHA256 `40d365715913c9da98579312b702a82c18be219cc2a73407c4526f58eba950af`；本机代码运行只有推理，无反传或写权重。2021 [原论文](https://arxiv.org/abs/2103.00020)报告其家族借约4亿互联网图文配对训练，这**不是**我们的5000图训练量，也不能由本机检索分数反推确切的 ViT-B/32 所见每张训练图。
- 对同一作者内部COCO2017 val子集的500图片、每图首句人写描述，本机当前权重的500候选图→文 R@1 60.2%、文→图 R@1 54.4%；原始照片与官方CLIP预处理输入，详情/哈希在 `work/results/c35_external_clip_retrieval.json`。这是继承大量外部训练的能力演示，**不与本机随机小模型作同资源算法胜负**。外部训练互联网资料与这500张 COCO 照片是否存在重复，当前无法由不可取得的全部外部训练图逐字节核对，状态 UNKNOWN；不可称严格从未见过图片。
- 这份 CLIP 只会给图文整体相关分数，图文检索好不证明已学会回答每一道空间关系题、逐区域指称、从文字生成图片或判断问答真实性。
