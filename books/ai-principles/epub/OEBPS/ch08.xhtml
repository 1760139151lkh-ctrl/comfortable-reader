第八章　没有标签时，记录还能告诉我们什么

第七章给一株花作判断时，每株旧花都有已经知道的类别。近邻要听邻居的类别，树要数一个区域里两类各有多少，支持向量机也要看每株分数是否站在正确一边。若拿走这些答案，计算并不会自动停止，但问题已经换了：眼前只有许多行测量，我们究竟想从中留下什么？

有两件事值得分别试。第一件是用少数连续数概括一行里的多项测量，日后仍能大致还原原来的数；第二件是只给每行一个有限的组号，让同组共用一个代表记录。前者关心少丢多少变化，后者关心代表点离原记录多远。它们都能在没有类别标签时运行，却不能仅凭算出了坐标或组号便声称发现了资料背后的真实原因。本章先把这两种较朴素的任务走通；“假设有看不见的群体，它以某种概率产生观测”要另列模型和证据，不能让几何分组偷渡成因果故事。

一本只有消费记录、没有“客户类型答案”的账

UCI 于 2014 年收录了一份批发商客户资料：440 行，每行有 Fresh、Milk、Grocery、Frozen、Detergents_Paper、Delicassen 六类商品的年度消费额，单位由资料称作 monetary units。表中还记着渠道和地区；UCI 页面甚至把 Region 标作某些分类任务可以预测的 target。若我们的任务改成“根据消费预测地区”，那就有地区标签。但这里问的不是地区或已有渠道，而是没有逐项答案的消费结构；这两列并非“隐含客户类型”的标准答案。本章的计算只读六项消费额，程序连画图、挑初值和评分都不会让渠道、地区参与。资料没有给每行具体消费年份，我们也不拿它演未来时间预报。(UCI 原资料与许可；本机原包身份)

原文件第一行就能给问题一个形状：六项依次为 12669,9656,7561,214,2674,1338。这行显然不是六个“类别”的答案，而是同一位客户在六类商品上的数值。若要把它与另一个客户相比，究竟先看总消费规模，还是看奶、杂货与生鲜各占的关系？若只保留两个数，丢失的四个方向该如何计代价？我们必须先选问题，算法才知道何为相似。

这样的表很容易诱人说“程序会自动找出两种客户”。先停一下：客户也许因规模、菜单、供货条件或许多未记录原因而不同；同一人一年里各类消费还会互相影响。六个数足以让我们计算相似、共变和重建误差，但没有任何一列替我们核验“真正有几种人、每种人为什么那样买”。这个区别贯穿本章。若以后要把分组用于真实决策，还需要另问收集资料与采取行动的目的和后果；本章只研究怎样表示这批已见数。

六项都非负，大小范围却很不一样。官方表和本机原件中，Fresh 从 3 到 112151，Detergents_Paper 从 3 到 40827；同一栏也有少数远高于中间水平的记录。若直接把六项原数平方相加，巨大消费额便容易主宰“哪两行接近”。这不是电脑犯错，而是我们未经讨论就让货币差的平方成为唯一关心的尺。

先定本章要用的尺。对每项非负消费 x，取 log(1+x)：它保留大小顺序，却把特别大的差压得更紧。例如从 100 到 200，原数差 100，变换后差约 log(201)−log(101)≈0.688；从 10000 到 10100 原数也差 100，变换后却只差约 0.010。这等于选择更重视相对比例而不是同一笔绝对差。随后，只用拟合段求六列各自的平均 μj 和标准差 sj，把变换后的每列除成 zij=[log(1+xij)−μj]/sj。六列便在拟合段上各有均值零、方差一。取对数和标准化都是我们的建模选择，原始账本并没有自己变成这些新数；别的尺度会得到别的“接近”和“主要方向”。

为避免把留出记录提前掺进这些选择，运行前约定按原行号用固定种子把 440 行分成 352 行拟合、88 行留出。这份表没有逐行时间，所以这个随机切分只检查“同一档案里暂未参与拟合的行怎样”，不代表下一年的新客户。留出行使用拟合段的同一 μj,sj，不能再帮助决定它们。

一条穿过点群的线，和一张不能被当作答案的地图

回头看这条数学路线，比“发明降维算法”的口号更具体。1901 年 Pearson 问的是：物理、生物等研究里，一批观测可同时在好几个坐标上带误差，怎样给这个点群一条整体最近的线或平面？如果只把某一项当绝对准确的输入、让另一项作输出，普通回归线回答的是另一种问题；他在意的是点到候选线的垂直偏离。我们的客户账本与他当年的测量不是同一资料，但“每项都有变化，想用较少坐标表示全体”的困难相通。(Pearson，1901，第 559—562 页)

1933 年 Hotelling 面对多项彼此相关的测验分数，还举过木杆物理属性、汇率等不同例子。他追问：是否能用较少的成分组织这些同时变化的量？他特意选择“component”而不把每个新数都叫作心理学里的“factor”，随后按成分对总变化的贡献排列。那个研究处境让新的坐标不仅是绘图方便，还有检验许多测量怎样一起变的用途。可是，“找到一组对方差贡献大的坐标”是数学结果；这些坐标是否就是世界里独立存在的少数原因，要另有假设和证据。不能因为原文提出了后一问题，就说今天对六项消费作一次分解已经回答了它。(Hotelling，1933，第一部分第 417—425 页)

现在从本章自己规定的目标推这条线。把第 i 行在六项对数标准化后的数写为向量 zi∈R6。想只留下一个连续坐标，就选长度为一的方向 v，记这一行在方向上的位置为 ti=v⊤zi。若只凭这个数还原，最直接的近似是 z^i=tiv：读者可检验，z^i 确实只能落在穿过原点的那条线上。两者的平方距离为

‖zi−z^i‖2=‖zi‖2−(v⊤zi)2,

因为 v 长度为一、余下部分同 v 垂直。第一项不随方向变，所以要让所有记录的平均重建误差尽量小，等价于让投影 (v⊤zi)2 的平均尽量大。

记拟合段的六维矩阵为 Z，每行一位客户；六列已在拟合段居中。令 S=Z⊤Z/352。刚才“保留最多平方投影”的量正是 v⊤Sv。带着 ‖v‖2=1 的约束，考察 v⊤Sv−λ(v⊤v−1)：对 v 求导为 2Sv−2λv，驻点须满足 Sv=λv。并非任意特征向量都好：最大特征值对应的单位方向才给最大的 v⊤Sv。第二个方向须同第一个垂直，再在剩下的方向里保留最多变化；依次走下去便得到主成分分析，英文 Principal Component Analysis，简称 PCA。在它首次承担计算责任时，名字终于指向了明确的对象、目标和限制。

对一维近似，拟合段平均误差是总方差减去第一特征值；若留下前两条正交方向，近似变成

z^i=(v1⊤zi)v1+(v2⊤zi)v2,1352∑i‖zi−z^i‖2=∑j=36λj.

这是正交投影留下的误差恒等式，不是“保留了资料意义的多少百分比”。每个方向可整体乘负一而不改变投影或重建；程序为了画图稳定，规定绝对值最大的系数为正。这个符号约定也提醒我们：PCA 坐标的正负不自带业务褒贬。

本机拟合段的六个特征值从大到小约为 2.655、1.678、0.622、0.585、0.290、0.170。六列各在拟合段标准化成方差一，所以总和约为 6。第一方向占这套尺度的约 44.25%，前两方向合计约 72.22%。用一条方向重建六维记录，拟合段平均平方误差约 3.345，留出段约 3.613；用两条方向则分别约 1.667 与 2.043。开头那行原记录在拟合段，经同一对数和缩放后，前两项连续坐标约为 (1.345,−0.414)：我们用两个数替代六个数，不是给客户改名。留出误差较大只是这份有限切分上的观察，不足以从中编出“后来客户变了”的时间故事，因为原件根本没给每行历年。

方向到底在量什么，也不能只给它取一个营销名字。第一方向在本机这份拟合表上，对 Milk、Grocery、Detergents_Paper 的系数约为 0.546,0.574,0.549，对 Fresh、Frozen 的系数较小且为负；第二方向对 Fresh、Frozen、Delicassen 的系数约为 0.593,0.598,0.518。这让我们能具体说，哪些已经标准化的消费列把点推向图的右边或上边；不能说“第一成分就是零售性格，第二成分就是客户意图”。方向来自这 352 行的共同变化、我们预先选的对数尺以及相应特征值，换条件就可能转动。

若只能传一个组号，六个数要交给谁代表

PCA 留下的是连续的坐标。若通信或存储只允许从有限的几个编号里选一个，问题便不同了。Lloyd 研究脉冲编码通信时，发送端不把每次的实际电压原封不动传过去，而报它落在哪个区间；接收端把该区间的一个代表电压当作原值。区间和代表值要选得让平均平方量化误差小。他在 1957 年的会议上报告过部分内容，论文到 1982 年才发表；不能把发表年份误当他第一次面对这个问题的年份。(Lloyd，1982，首页脚注及§I—V)

MacQueen 1967 年从另一侧把多维分组说得更清楚：一个人看见多维的点，只能向另一人传 k 种消息之一；收到消息的人拿相应代表点代替原点。若差错按平方距离算，最佳代表是那一组点的平均，而点应归到离自己较近的代表处。这是分组同时也是一种有损的表示。Lloyd 面对通信电压，MacQueen 面对多维分区；两件事在平方损失上相遇，不需要虚构后一位直接沿前一位的论文工作。他的论文把逐个新点到来、更新最近组均值的过程称作 k-means，并不宣称每次都会得到全局最好的划分。论文还记载了 Forgy、Jennrich 在 1960 年代提出过全体点反复重分组的办法。我们当前要运行的是后一类批量交替，不能把电脑循环逐行署成 MacQueen 原来的在线程序。(MacQueen，1967，第 281—283、294 页)

把这个问题放到客户账本。沿用前面六维标准化的 zi，只准两种组号 gi∈{0,1}，为两组各留一个六维代表点 c0,c1。一行只要报告自己的组号，重建时便用 cgi 代替它。平均平方损失是

J(g,c)=1n∑i=1n‖zi−cgi‖2.

这项数衡量的是在已选择的六项对数标准化尺度里，代表点与原记录有多远。组号 0、1 不是资料提供者写下的客户类别；交换两个号，损失完全一样。

为什么会有“找最近中心”和“重新求均值”两个动作？先固定 c0,c1。每行 zi 选距离较小的那个，便使自己在求和中的那一项最小；行与行的这个选择互不妨碍。再固定每行所属的组。对其中一组的代表 c，平方距离和展开成 ∑i(‖zi‖2−2c⊤zi+‖c‖2)，对 c 求导为 2ngc−2∑i:gi=gzi，令它为零便得 c=1ng∑i:gi=gzi，即该组均值。两步轮流做，目标 J 每一步都不会增加；这是一种两代表点的 k-means 聚类。这里“聚类”只说按所选距离把记录组织到组，绝没有给我们一列真正的“客户天性”标签。

非增不等于找到了全局最小。不同初始代表点可能通向不同稳定分组，前提是某轮不要出现无人归入的空组。协议先规定从拟合段取两行作起点，使用五个固定种子 11、22、33、44、55，分别运行到分组不变；只按拟合段的 J 选其中较小的一次。五次训练目标约为 4.1627,4.1627,4.1628,4.1646,4.1627，我们按目标和平手顺序用种子 11。这些数字接近，但确实不完全相同；它们说明程序没有凭“一轮收敛”获得全局最优证明。后面的 88 行只交给已经定好的两个中心，不参加初值或重选。

最后的几何分组在 352 行拟合段里有 197 与 155 行；88 行留出资料按同一中心归入两组，有 53 与 35 行。拟合段平均平方距离约 4.163，留出段约 4.546。若只准一个代表点，最佳点是拟合段平均向量零，平均平方距离恰为六列方差之和 6；两个代表点让这项训练目标下降，但继续增加代表点本来也只会让训练目标不升，这不能证明自然界恰有两种客户。开头那行原记录在本次算法里得到组号 1；组号只让程序知道重建时取哪一个六维代表，不会自动解释它为何采购。

两组在原始货币尺度上的中位数还能帮我们描述本表的差异：组 0 的 Fresh、Milk、Grocery、Detergents_Paper 中位数约为 9898,1801,2313,311；组 1 约为 5626,7503,11055,4314。这不是“客户 0 喜欢生鲜、客户 1 是零售店”的结论。算法从六项对数标准化数出发，组号按第一主方向的位置排列；原始中位数只是回到原表描述这次分出来的行，没有揭示采购动机，更没有证明两组在别的批发商处仍存在。

开头选择 log(1+x) 时，我们说过它会改变“接近”的含义。现在保持同一 352/88 行切分、同样两组、同样五个初值种子，只撤去对数变换：六项原消费额仍各自用拟合段的均值和标准差缩放。你可以直接运行 python work/code/wholesale_unsupervised.py --transform raw；结果和原数尺度的图另存，不覆盖本章默认的对数版本。原数尺度下，两个中心把拟合段分成 325 与 27 行，留出段是 86 与 2 行；默认对数尺度则是 197 与 155、53 与 35。原数尺度那组较少的行，在 Milk、Grocery、Detergents_Paper 上的原始中位数约为 22044,28540,13726，显示它更集中在这几项特别高的记录上。

两次运行都在训练段把每一列缩成方差一，却没有因此让“大额记录对整体形状的影响”自动消失：先取对数和只作线性标准化，改变的是行与行之间的距离、共同变化及中心的位置。原数版本前两方向留下约 73.48% 的拟合段方差，对数版本是 72.22%；这两个百分比的分母来自两张不同尺度的表，不能把较大的那个当作“更真实地理解客户”。同样，两个版本的平方距离数值也不是对同一损失的公平冠军赛。若任务更在意采购额的绝对差，原数尺度可能有理由；若更在意相对变化，对数尺度有理由。需要哪一种，应回到真实用途，而不是让哪张图看起来分得更整齐来代选。

左图每个圆点是拟合段的一行，颜色是六维 k-means 的输出，两枚大叉是六维中心投到前两主方向之后的位置。聚类发生在六维，绘图只显示二维，因此图上看似靠近甚至交错的点，仍可能在没画出的四个方向上离得远。右图把六个方向各自留下的拟合段方差列出来；前两柱的合计是 72.22%，其余并未变成零。图里没有客户类型的颜色真值，也没有把渠道或地区当正确答案。

两种压缩留下的东西不同

现在可以公平比较目的，却不能把两行平方误差直接排成“谁更懂”。PCA 给每行留下两个连续实数，外加全体共用的两条方向；两中心聚类只给每行一个二选一编号，外加全体共用的两个六维代表点。即便两项损失都由平方距离算，它们付出的表示预算也不同。更何况 PCA 的误差是把记录投回一张二维平面，k-means 的误差是把记录压到两处离散点。数值上 PCA 前两方向的拟合／留出误差约为 1.667／2.043，两中心则约为 4.163／4.546；仅凭前者较小，不能说连续两个数与一个组号完成了同等的压缩工作。

它们之间也没有严格的“连续坐标好，所以先 PCA 再聚类”必然关系。本次聚类直接在六维拟合，二维图仅供人看；若先丢掉四个方向，再在两维找两个中心，行与行的距离会改变，就成了另一个实验。反过来，聚类颜色看上去沿第一主方向分成两边，也不意味着 PCA 发现了两种客人。第一主方向只解决最大方差的线性重建，聚类只解决固定 k=2 的平方距离，两者没有关于真实群体的共同证明。

一个四点小例让这种界限更明显。把四个点放在 (−1,−1),(−1,1),(1,−1),(1,1)，均值为零，两个坐标方差相等、协方差为零。PCA 的两条特征值同为 1，所以“唯一最重要的一轴”根本不存在；水平和竖直方向一样能保留一半平方变化。若只给两个代表点，按左／右两组或按上／下两组，各能得到平均平方距离 1。两种分组同样合法，不能靠给组取漂亮的名字选出其中一个“真实原因”。我们的 440 行并不呈完美方形，但数学反例提醒我们：目标明确也不保证表示或分组有唯一的世界解释。

同一份程序里，哪一步留下了什么

完整 Python 程序只需这台电脑已有的 NumPy 和 Matplotlib。它先核原 ZIP、CSV 的字节身份及 440 行格式，再按协议切分。下面从预处理函数与 PCA 函数各摘几行并排放在一起，便于追踪同一矩阵怎样流过两处；两组五次起点和留出评分的完整控制流都在链接的文件中。

log_fit = np.log1p(raw_fit)
log_holdout = np.log1p(raw_holdout)
mean = log_fit.mean(axis=0)
std = log_fit.std(axis=0)
z_fit = (log_fit - mean) / std
z_holdout = (log_holdout - mean) / std

covariance = z_fit.T @ z_fit / len(z_fit)
eigenvalues, directions = np.linalg.eigh(covariance)

axis=0 的意思是沿客户行求每一商品列的均值和标准差，不是把同一客户的六项消费混在一起平均。随后 Z 的形状是 352×6，所以 Z⊤Z 是 6×6：第 j,k 格记录的是两列在所选尺度下怎样同起同落。eigh 给对称矩阵的特征值和方向，程序再从大到小排序、规定每个方向的显示正负，并分别在拟合和留出段投影重建；它执行的是前文已经推过的最小重建误差问题。

两中心的核心计算同样能在程序里指认：

groups = np.argmin(squared_distances(z_fit, centers), axis=1)
new_centers = np.stack([
    z_fit[groups == j].mean(axis=0) for j in range(2)
])

squared_distances 生成“每行到两个中心各有多远”的 352×2 表；argmin 沿第二轴找每行较近的一个，得到 352 个临时组号。下一行只在各组内部沿客户轴求均值，不读 Channel、Region 或留出行。程序会检查空组、目标是否意外升高、是否在 100 轮内稳定；没有把“稳定”打印成“真实类型已找到”。它另把每行的原行号、拟合／留出身份、算法组号和两项画图坐标写进逐行结果，让图的颜色可以回查。

从看见结构，到敢说“背后有原因”

我们已经能在没有类型标签时作两件完整的事：用 PCA 找一组连续坐标，在选定尺度下尽量少丢平方变化；用两中心聚类给每行一个离散编号，让它尽量靠近本组代表。这些新对象各有清楚的输入、目标、算法、可运行结果和失效条件。它们还没回答另一种问题：若一行落在两个代表附近，能否说它属于每种隐藏情形的机会分别是多少？若表中某项消费缺失，能否借剩余项推它？只靠几何距离没有规定“这些数字原本怎样出现”，因此也不能由两组颜色倒推出真实成因。

下一章会在这个缺口上明确新增假设：暂设有看不见的类别 Z，每种类别以自己的概率分布产生我们能见到的六项数。我们再问如何把未见的 Z 从总概率里消去、怎样利用不确定的组别反复估参数，以及资料是否足以辨认那个解释。这个 Z 是模型选择，不是 UCI 文件里还有一列我们忘了打开的正确标签；概率图与推断也必须从这个具体问题里长出来，而不是因为地图上列了名字就突然出现。
