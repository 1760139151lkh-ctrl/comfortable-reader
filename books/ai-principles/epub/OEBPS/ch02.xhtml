第二章　判断已经对了，为什么还要量分数的距离

第一章结束时，七张卡片都被直线 z=x1+x2−3 分到了正确的一侧。再看其中两张：标签同为 −1 的 (1,1) 与 (0,0)，得到的分数分别是 −1 与 −3。若任务只问类别，它们都答对了，没必要假装第二张仍然“分类失败”。可是，假如我们希望开关前的数值本身接近某个给定目标，两张卡片又不一样。我们究竟要改善类别，还是要改善开关前的分数？先选清目标，更新公式才有意义。

这个问题曾直接出现在自适应电路的工作台上。电路在给出二值决定之前会产生连续电压；研究者能够测量它与参考信号的差，再利用这份差改变电路。我们先看当时实际要解决什么，再回到同一批卡片，借用其中能够明确计算的关系。

另一条同期路线：从信号预测走到自适应开关

上一章的早期研究线走到 Samuel 1959 年的总结，随后在证明处还借用了 1962 年的数学工作。现在把历史视线明确退回 1956 年，看与棋类和知觉研究并行的电子线路。Widrow 在 2005 年的回忆中说，自己当年短暂参加过 Dartmouth 的讨论，随后觉得完整的人工脑离当时的电子器件还很远，回到更可操作的信号处理问题。1957—1958 年，他已在研究一种能自行调系数的预测滤波器：若输入信号的统计关系没人预先交给设计者，就让信号流过带可调系数的装置，用实际预测误差估计表现，再逐步调整。这段时间顺序来自作者多年后的回忆；它帮助我们看见同期另一条研究路线，具体实验仍要由当时的论文核对。(Widrow，2005 年回忆，第 100—101 页)

同一回忆还记述：1958 年，Richard Mattson 在可调的线性组合后接二值开关，研究这种装置可以实现哪些图形分类；1959 年 Widrow 到 Stanford，开始与 Marcian Hoff 合作。硬开关在大多数小改动下不变，错类次数难以提供局部调整方向。两人转而试着用一次输入、一次连续误差，给原先需要反复测量平均误差的调整过程一个便宜的方向。1960 年的公开论文让我们进一步核查这种选择怎样被陈述、演示和分析。(Widrow，2005 年回忆，第 101—102 页)

1960 年，Bernard Widrow 和 Marcian Hoff 发表《Adaptive Switching Circuits》。他们开篇从开关电路谈起：铁路道岔的联锁等控制规格必须准确执行，设计者可以列出应有的输入与输出，再实现相应电路。接着他们把视线移向另一类问题：已知一串相关的二值信号，利用过去若干位预测下一位。下一位出现前，设计者不知道每种历史后面都该接什么；预测错一次有代价，但可以比较许多次预测的平均表现。论文设想若观察前 24 位，可能的历史便有 224 种，手头约一百段例子填不满这张表。这个数字是论文用来解释困难的设想，不是他们后来展示的硬件曾在全部历史上训练。(Widrow 与 Hoff，1960，第 96 页)

值得尝试的是一种受限制的装置：不替每种完整输入保存一个答案，而让许多输入共用可调的增益。它先把输入乘上各自的增益并相加，再决定正负类别。这里没有数学定理保证这样的线性装置对所有开关任务都够用；论文自己就指出，它能实现的二值规则只占全部规则的一部分。选择它，是用较少、可从例子调整的数换取一种可操作的概括方式。前章的感知机也有线性分界，但 Widrow 与 Hoff 此刻关心的测量和改权依据不同，不能因形状相似就把两种训练法说成同一个算法。(原论文第 96—97 页)

论文展示的一台可调线性装置称为 Adaline（adaptive linear），用 4×4 个开关摆出简单图形，再用参考开关表示希望得到的类别。十六路输入的增益与一项不随图形变化的增益先形成加权和；示意图随后画了把它变为二值输出的部件。但在那台演示装置上，这个量化部件并未作为独立器件装好，操作者承担了相应判读。训练时更关键的是另一只表：它读量化之前的加权和与参考输出的差。操作者逐项调增益，试图使这张图形的表针回到零，再换下一张图形。六种图形反复出现后，论文给出误差平方随训练图形数变化的曲线。这里有真实器件、参考开关与人的操作；我们后面的 Python 循环只是借此看懂为何保留连续误差，不是它的硬件复刻。(原论文第 97 页及图 2—5)

论文后半部分才把问题写成统计目标：一批输入与希望输出给定以后，怎样让加权和的平均平方误差尽量小？把线性加权和放进平方误差后，关于各个增益只会出现常数、一次和二次项；论文由此研究这个目标的最低处。单张图形的当前误差和输入符号，又足以给出该图形的导数方向。这个理论选择把刚才的表针读数变成了可计算的调整信息。作者也分析了在附加噪声假设下，均方误差与分类错误率的关系；这不允许我们对任何数据都说“均方最小就必然错类最少”。同篇论文另报告了一组带扰动的 3×3 字母图形模拟：四次各自选取训练图形的实验，在一百张图形上的错误数分别为 25、19、20、28，表现有波动。这些是当时的实验记录，不是我们的七张卡片的成绩。(原论文第 97—100 页，式 (9)—(13) 与图 10)

先决定量什么，再给它一个名字

回到第一章。每张卡片仍有输入 x=(x1,x2)、已给类别 y∈{−1,+1}，同一模型仍算

z=w1x1+w2x2+b.

类别只取决于 z 是否大于零。若评价只统计判错次数，第一章末尾的参数已经得到零次错误；这个计数没有要求 −3 变成 −1。上一章的感知机更新也是看 yz 是否不大于零，再沿样本方向改参数；它不是对下面的平方目标求导。

现在作一个明确的新选择：把 +1 和 −1 不仅当作类别代号，还当作我们希望开关前分数靠近的两个数。对一张卡片，令残差 r=z−y，选择

ℓ(w1,w2,b;x,y)=12(z−y)2=12r2.

残差可正可负，直接相加会互相抵销；平方后每张卡片都给非负代价，偏得越远，代价增长越快。前面的 1/2 只让导数少一个 2。平方误差或平方损失就是这个已说明用途的量，不是“分类问题天生的正确答案”。

这个区别在已经答对的卡片上最醒目。第一章给 (0,0) 的标签是 −1，分数为 −3：分类正确，但残差为 −2，单张平方损失是 2。若一个正类得到分数 10，类别也正确，它的平方损失却是 12(10−1)2=40.5。连续分数不是未经说明的“置信概率”，更大的正数也不总表示这个新目标做得更好。若我们只想少判错，不愿惩罚这种高分，就该考虑别的目标；第一章按类别修正的办法也仍有它自己的用途。

差一点的数，怎样给三个参数一个方向

先只看一张卡片，把输入补上一个恒为 1 的分量：x~=(x1,x2,1)，把三个可调数合成 v=(w1,w2,b)。于是 z=v·x~。这种写法没有增加新的学习参数，只是让偏置与两个权重接受同一种计算。

若只把第 j 个参数增加很小的 h，分数增加 hx~j，残差也增加同样的量。平方损失的变化可以直接展开：

12(r+hx~j)2−12r2=rhx~j+12h2x~j2.

用这个变化除以 h，再让 h 趋近于零，得到 ∂ℓ/∂vj=rx~j。把三项偏导按参数顺序排成一个向量，称为这张卡片的梯度：

∇vℓ=rx~=((z−y)x1, (z−y)x2, z−y).

它说的不是“模型懂了自己哪里错”，而是：在当前参数处，分别轻微改变这三个数时，我们刚选的平方目标怎样变化。

因此可以沿负梯度试一步：

v新=v旧−ηrx~=v旧+η(y−z)x~,η>0.

步长 η 由训练者选，不由导数自动保证。这里先求导、再改参数是两个动作。这个逐样本的连续误差更新，如今称为最小均方更新，英文 Least Mean Squares，简称 LMS；原论文第 99 页明确写出了单样本平方误差的相应偏导。Widrow 在 2005 年回忆，LMS 这个简称是另一名学生 James Koford 稍后提议的。论文里的实物调整与我们写的 Python 循环仍需按各自做过的事理解。(Widrow，2005 年回忆，第 102 页)

这一步对当前卡片的作用无需凭感觉猜。记旧残差为 r，把新参数代回同一输入，有

r新=(v−ηrx~)·x~−y=(1−η‖x~‖2)r.

所以，只要旧残差不为零，且 0<η‖x~‖2<2，这一张卡片的平方损失会严格下降；取 η=1/‖x~‖2 恰能把这一张的残差一次消掉。步长过大则可能越过目标，反而更远。这个结论由线性分数给出的是精确等式，不是所有模型、所有样本共同改善的保证。

还用第一章第一张卡片 x=(2,2),y=+1，从零参数出发。增广输入 x~=(2,2,1) 的平方长度是 9，初始损失是 1/2。若沿本章规则取步长 0.1，新参数为 (0.2,0.2,0.1)，分数 0.9，损失 0.005；步长改成 0.3，分数会冲到 2.7，损失变成 1.445。上一章的感知机在首张卡片取步长 1 时把分数推到了 9，它已经完成了“判到正侧”的任务；若拿本章的平方尺去量，那一步的平方损失会从 0.5 变成 32。两种算法服务不同训练目标，不能拿新尺宣布旧任务毫无价值。

一张改善，不等于七张的平均改善

七张卡片共享 v。我们若关心整批训练记录，就要明确平均的是哪七个数：

L(v)=17∑i=1712(v·x~i−yi)2,∇L(v)=17∑i=17(v·x~i−yi)x~i.

每个残差在同一组旧参数上算出，七个方向相加再除以 7，这叫一次完整批次的梯度。若处理第一张就立即改权，第二张看到的已是新参数，那是逐样本更新，不能把两种循环仅因公式相似就说成同一次计算。

沿第一章保存的 v=(1,1,−3) 看一次。七张卡片的分数是 1,1,1,−3,−1,−1,−1。只有 (0,0) 的分数偏离它的目标 −1，残差为 −2，于是全批损失是 2/7，梯度是 (0,0,−2/7)。若批次步长取 0.1，第一次更新仅把偏置改为 −3+1/35，两个权重暂时不动。那张 (0,0) 卡片更接近目标；原来残差为零的另外六张则出现一点偏差。逐张都变好从来不是这一步的承诺，七张的平均损失才是我们要求下降的量；本机算出的平均损失从约 0.285714 降到 0.277959。判断依据是已选目标，而非“更新了就是学好”。

完整的本机程序保留第一章的七条记录，并核对它们与上一章结果文件中的数据一致。程序把上面的参数向量 v 叫作 theta，把七张卡片叫作 records，把批次步长叫作 rate。计算仍能沿每个数追踪：

def mean_square_gradient(theta, examples):
    grad = [0.0, 0.0, 0.0]
    for features, target in examples:
        x1, x2 = features
        residual = score(theta, features) - target
        grad[0] += residual * x1
        grad[1] += residual * x2
        grad[2] += residual
    return [component / len(examples) for component in grad]

rate = 0.1
gradient = mean_square_gradient(theta, records)
theta = [theta[j] - rate * gradient[j] for j in range(3)]

函数内先累计三个参数各自收到的七张卡片的贡献，最后才沿样本轴求平均。最后一行才修改参数；调用梯度函数本身不会改变 θ。列表推导式按 j=0,1,2 分别把旧参数减去步长乘导数。若漏掉除以 7，同样的步长会使更新幅度扩大七倍，计算的就不再是上式规定的平均目标的一步。

def mean_half_square(theta, examples):

终点为什么是这三个数

若只看训练曲线，我们不知道 0.107143 是否是所选目标在这个模型族里的最低点。这里数据少，可以直接算出来。不过在列方程前，先弄清它究竟在寻找什么。把七张卡片的增广输入 x~i=(xi1,xi2,1) 依次排成一个 7×3 表 X，把七个目标排成列向量 y。同一组参数 v 在七张卡片上给出的分数就是 Xv，平方目标可写为

L(v)=114‖Xv−y‖2.

这不是为了换一种高阶写法。X 的三列分别列出“第一项测量在七张卡片上的取值”“第二项测量的取值”和“一列恒为 1”；你能用这三列的线性组合形成某些七维分数表，却不能随意指定七个分数。训练所做的是在这组参数能够形成的分数表里，找一张离目标表 y 最近的。若把某个参数轻微改动，七个分数会沿对应的那一列一起移动；在最近点，残差 Xv−y 与三列各自的内积必须为零，否则沿某一列稍走就还能缩小平方距离。这正是已推过的三个梯度分量为零，简写为 X⊤(Xv−y)=0。

现在把七条卡片的 x12,x1x2,x1 等分别相加，将这三个“残差与一列输入的内积为零”写开，得到

19w1+11w2+9b=3,11w1+19w2+9b=3,9w1+9w2+7b=−1.

第一式里的 19 是七张卡片的 x12 之和，11 是 x1x2 之和，右边的 3 是 x1y 之和；其余各项同样能回到原表逐项核算。这样的方程并非凭空出现的“最佳权重公式”，它只是把已推导的平均梯度设为零。

前两式相减给 w1=w2=a。再把它代回，得到 10a+3b=1 和 18a+7b=−1，解得 a=5/8, b=−7/4。为什么令梯度为零之后就可以说它是最低点？把这组参数记为 v*，在它旁边任意改动 Δ。每张卡片的残差会从 ri*=v*·x~i−yi 变成 ri*+Δ·x~i。展开七张的平方差，得到

L(v*+Δ)−L(v*)=Δ·∇L(v*)+114∑i=17(Δ·x~i)2=114∑i=17(Δ·x~i)2.

第一项因为梯度为零消失；留下的平方和不可能为负。三张卡片的增广输入 (0,0,1),(2,0,1),(0,2,1) 彼此独立，因此若 Δ≠0，至少有一张卡片的分数被它改变，平方和严格为正。这才证明它是这七张训练卡片、这组数值目标、这一族线性分数的唯一全局最小点。代回七张卡片，损失为 3/28，与程序终点相合。

可以把刚才的“垂直”在具体数字上检查，而不把七条残差误认为都必须为零。按表格顺序，最小点的残差是

(−14,−14,−14,−34,12,12,12).

它们加起来为零；分别乘上七张卡片的第一项、第二项测量后再相加，也都为零。这是残差与 X 的三列正交，不是每张卡片都恰好达到指定数值。七张卡片给了七个目标数，本模型却只能沿三列共同改变它们；平方最小点正是这样一种有结构的折中。程序现在把这三项内积写在结果里，本机算到的都是零。

它和感知机的 (1,1,−3) 都把七张卡片分对，却给出了不同分数。目标不同，最合适的参数就可能不同；“训练损失更小”在这里没有创造新的可分规则。如果把目标类别的数值从 ±1 同时改写为 ±2，目标列 y 整体乘 2。由于可实现分数表 Xv 的三列并没变，原最小点和参数都随之乘 2，平方损失则乘 4；类别判断仍保持不变。这再次提醒我们：分数的数字大小受目标编码影响，不能直接叫作置信概率。

不必改坏默认文件来试这件事。在项目根目录运行 python work/code/continuous_error_cards.py --target-scale 2；它重新读取第一章的原卡片和默认模型，只把本次训练目标及起始参数同步乘 2，把结果另存为带 scale_2 的文件。本机结果给 (1.25,1.25,−3.5)、平均平方损失 3/7，仍是七张分类全对。若只把标签乘 2、起始参数却保持原值，这会是另一个初始条件；最终精确最小点仍可比较，但不能期待逐步曲线也逐项按同一倍数缩放。这里把两个条件一起改，是为了单独核对目标编码造成的尺度关系。

这条路的收获与停点

我们现在能完整回答本章开头的问题：连续误差提供比“判对还是判错”更细的训练信息；平方把正负偏差变成可相加、可求导的目标；每个输入分量使相应参数获得一个可计算的方向。一步的真实作用和步长范围可以推出来，多张卡片的共同目标也能在代码里逐项核对。选择这把尺有代价：它会惩罚已经判对但离指定数值远的分数，而改好一张还可能扰动别张。

七张点卡片到这里完成了使命。只换训练目标，z=w1x1+w2x2+b 仍是一条直线；第一章证明过的异或四点，继续无法由这一族分数全部分开。下一章需要重新问：能否在最后判断前先形成有用的中间表示，并让末端目标的变化告诉更早的可调数该怎样改？我们会沿当时真正尝试过的结构与学习办法进入这个问题，再建立相应的数学关系。

自己核对一次

  1. 在第一章的最终参数上，不运行程序，算出七张卡片的残差、平均平方损失及三个平均梯度分量。指出第一次完整批次更新为什么只改偏置。
  2. 对 x=(2,2),y=1 的单张卡片，从零参数出发，求使这张卡片的残差一次归零的步长。若步长加倍，平方损失会怎样？为什么这不能证明其他六张也变好？
  3. 暂不运行，预测 python work/code/continuous_error_cards.py --target-scale 3 的精确最小参数、平均平方损失和分类错数，然后运行核对。说明为什么目标编码乘 3，并不使模型对自然新数据的把握乘 3。

核对。第一题的残差为 0,0,0,−2,0,0,0，故 L=2/7、∇L=(0,0,−2/7)。第二题的增广输入平方长度是 9，故步长 1/9 把当前残差化为零；步长 2/9 使新残差成为旧残差的负数，平方损失恰与原先相同，不能由此推其他样本。第三题的精确最小点为 (15/8,15/8,−21/4)，平均平方损失为 9×3/28=27/28，七张卡片分类仍全对。把旧参数和目标同时乘 3，每个残差也乘 3，损失乘 9；反向除以 3 又能回到原问题，故新最小点恰是旧最小点的三倍。它只改变这份人工任务中类别数字的编码，不提供关于未见自然数据可靠性的任何新证据。
