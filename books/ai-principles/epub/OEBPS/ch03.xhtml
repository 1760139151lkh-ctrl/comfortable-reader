第三章　中间表示怎样得到调整方向

第二章把同一条直线的分数拉向了目标值，七张卡片的平均平方误差确实下降了。可它始终是一条直线。第一章那四张异或卡片——恰有一项为 1 时是正类，两项相同则是负类——已经给出一个严格的边界：无论怎样调整 w1,w2,b，分数 w1x1+w2x2+b 都不能同时分对四张。继续换步长或多训练几轮，不能创造这族分数里不存在的那条边界。

一个可以认真尝试的改变，是让最后的判断先读到一些由输入计算出来的中间量。例如直接算 p=(x1−x2)2：四张卡片的 p 依次为 0,1,1,0，末端用 s=2p−1 就全对了。这里没有训练秘密，我们亲手把有用的中间量交给了程序。它证明“换表示”能解决眼前的表达问题，也留下更难的一问：面对不知该手造什么特征的任务，程序能否连中间量本身一起调整？

从一个中间单元，到可以学习的两个

先取一个与前章线性评分相似的部件：它算 z1=a11x1+a12x2+c1，再把这个数交给一个非线性函数，得到中间活动 h1=tanh(z1)。tanhz=(ez−e−z)/(ez+e−z)，输入很负时接近 −1，很正时接近 +1，中间平滑变化。末端若只算 s=b+v1h1，这个网络虽然比单个加权和多了一步，却仍分不开异或：tanh 按输入大小单调变化，最后对 h1 作一次阈值判断，相当于对原来的 a11x1+a12x2+c1 作一次阈值判断，边界依旧是一条直线；v1=0 时结果甚至只是常数。

再给末端两个这样的活动：

zj=aj1x1+aj2x2+cj,hj=tanh(zj)(j=1,2),s=b+v1h1+v2h2.

这时程序的结构是“两项输入 → 两个中间单元 → 一个末端分数”；可改的参数是每个中间单元的两个输入权重和一个偏置、它们通往末端的两个权重，以及末端偏置，共 2×3+2+1=9 个。给某一张卡片算出的 z1,z2,h1,h2,s 是本次的活动，不是另外五个待保存的参数。这样的前馈结构是最小的一类多层感知机，常写作 MLP；“多层”指输入经过可调的中间计算才到输出，不能拿训练轮数冒充层数。

非线性在这里承担确切工作。若把两个 tanh 都拿掉，代入末端式再收集 x1,x2 的系数，仍只得到 A1x1+A2x2+B，多少个中间线性单元也不会摆脱单条直线。保留非线性后，两个单元可以先给出不同的区分，再由末端合起来判断。设 t=x1+x2，亲手选择

h1=tanh(6(t−12)),h2=tanh(6(t−32)),s=h1−h2−1.

当 t 分别为 0、1、2，分数约为 −0.995, 0.990, −0.995。两个异或正例都有 t=1，两种负例分别在两侧，于是四张都分对。这是手工构造的存在例子：它证明两个中间单元有足够的表达能力，没有证明训练一定会自己找到这组数。

在“中间层该学什么”上，研究并非一步到位

这个问题在 1960 年代并不陌生。Widrow 与 Hoff 的 1960 年论文除了单个 Adaline，还讨论过把两个可调单元组合起来：当组合需要某个单元给出正响应时，把希望的输出责任交给当前误差较小的那个单元，另一个暂时不动。这样可以让几个单元各自承担一部分图形判断；它使用了具体的责任分配规则，尚不是从共同末端损失向任意早期连接逐条求导。Rosenblatt 的《Principles of Neurodynamics》于 1962 年成书，已把三层串联以及更多层、交叉连接列为实质研究对象。它们提醒我们：多层的结构设想早于下面要讲的这套普遍链式训练；不同结构当时仍各有反馈和可分析性问题。(Widrow 与 Hoff，1960，第 100 页 F 节；Rosenblatt，1962，目录与作者内容说明)

1967 年，Amari 问了另一个紧挨着第一章边界的问题：若两类数据本来就互相重叠，线性分界不可能让每条记录都对，适应性的调整还能趋向什么目标？他把错误代价与离判界的距离联系起来，研究只根据当前样本作修正时平均风险怎样变化，又把讨论从线性判别推广到分段线性和更一般的判别函数。这是对不可完全分开时如何学习的认真回答；它并未把本章即将使用的两处 tanh 隐藏活动及其链式导数直接交给我们。(Amari，1967，《A Theory of Adaptive Pattern Classifiers》，摘要、§I、§V—VII)

到了 1969 年，Minsky 与 Papert 的《Perceptrons》把某些感知机类究竟能表达什么认真做成数学问题。他们分析线性汇合局部证据的装置，证明一些结构在指定条件下的限制，也讨论学习的前景。第一章的异或不等式让我们先在小尺度上看见表达限制是什么样；它不允许我们把本书概括成“所有多层网络都被证明无用”。更实际的教训是：应先分清所选结构能否表示目标，再研究训练能否找到参数；两种失败不能混称“神经网络不行”。(MIT Press 1969 年原书资料与内容说明)

研究没有在 1969 年停住，后续也不只剩一种办法。1971 年，Ivakhnenko 用另一种方式组织多层预测：每层把输入成对交给低阶多项式，用训练资料拟合系数，再用另留的资料选出较有用的中间结果，送入下一层。这里的局部拟合仍用到了我们刚学过的最小平方思想，却没有要求每个早期系数都从末端损失接受同一条链式梯度。(Ivakhnenko，1971，§VIII—X)

1974 年，Werbos 的博士论文在复杂统计与动态模型中明确研究“按依赖关系向后求导”的链式关系。1976 年，Linnainmaa 在自己 1970 年关于浮点舍入误差的硕士论文基础上发表算法：先保存每一步的局部运算信息，再从最后一步往回，计算各处舍入误差对最终结果的影响。两者面对的都不是本章这四张神经网络卡片。它们显示求导工具与多层表示的构造在不同问题领域里发展；仅凭数学相似，无法断言某项工作直接影响了另一项。(Werbos，1974，Chapter II 页 II-85—II-88；Linnainmaa，1970 硕士论文书目及1976 年论文，算法 T)

1980 年的 Fukushima 从视觉图形的位置变化出发，研究可自组织的多层结构，让不同位置的相近形状引起相近的反应；1982 年 Hopfield 则分析循环连接的许多单元怎样形成可由部分线索唤回的记忆。它们追问的任务和获得学习信号的方式，与本章“给末端一个目标，怎样改前面的权重”并不相同，但证明这段时期的网络研究并非空白。具体视觉层级与联想记忆以后各有章节深入，眼前先保留它们在历史地图上的真实位置。(Fukushima，1980，摘要及§1；Hopfield，1982，原论文档案)

1985 年，Rumelhart、Hinton 与 Williams 的技术报告已经以“误差传播学习内部表示”为题；1986 年的《Nature》短文把问题说得尤其明白：任务只给输入和末端的希望输出，早期“特征分析器”的固定输入连接无法随任务学出新表示，真正可调的隐藏单元没有自己的标准答案。论文给出正向计算、由输出向前层累计导数的办法，并展示了镜面对称识别和家族关系等任务；其中镜面对称例子在 64 种输入上训练，图注给出 1425 次整批遍历。作者还明确说用较小的随机初值打破隐藏单元间的对称，并注明 LeCun 与 Parker 已独立得到相近变体。我们下面会用四张卡片算清这种对称为何会妨碍学习，但那不是原论文的镜面对称实验。这样才能准确说：这组工作清楚展示了共同末端目标如何训练内部表示；不能把链式法则、所有多层结构或此前二十年的研究都算成 1986 年突然从零诞生。(1985 年技术报告封面；Rumelhart、Hinton、Williams，1986，第 533—536 页，尤其第 535 页)

这些历史办法把当前数学问题变得更明确。我们可以手工写中间特征，也可以逐层筛选中间模型，或把末端损失对每个早期参数的影响算出来。下面选择最后一条路：它与第二章已经教过的平方目标和梯度接得上。这个选择有理由、有限定，也留下其他路线各自适合的任务。

末端有答案，中间单元该怎样改

仍只拿一张输入 (x,y)。把第二章的平方目标用在末端分数 s 上：ℓ=12(s−y)2，记残差 e=s−y。先问末端参数，办法与单层模型相同：只把 vj 改一点，分数随之改变 hj 倍，所以 ∂ℓ/∂vj=ehj；末端偏置的导数是 ∂ℓ/∂b=e。

前段没有“第 j 个隐藏单元正确活动应该是多少”的标签。我们问的是另一件可以计算的事：在当前参数处，把 ajk 改一点，最终损失会怎样动？这一点改动先使 zj 改变 xk 倍，再经过 tanh 改变 hj，经末端权重 vj 改变 s，最后改变损失。由前面给出的 tanhz 定义按商法则求导，导数是 4/(ez+e−z)2；把 1−tanh2z 通分也恰得到这个数，所以 dhj/dzj=1−hj2。把沿途的局部变化相乘：

∂ℓ∂ajk=(s−y)⏟末端残差vj⏟该活动怎样影响末端(1−hj2)⏟此处对输入还敏感多少xk⏟连接收到的数,∂ℓ∂cj=(s−y)vj(1−hj2).

这就是链式法则在一条实际计算路径上的用法。若某个 vj 为负，同一个“末端偏高”的残差可能要求该隐藏单元的早期权重往与另一个单元相反的方向动；把末端错误原封不动复制给每个中间单元，会算错。

有了各参数的导数，仍须另做一次更新，例如 ajk←ajk−η∂ℓ/∂ajk。反向传播指从已经得到的末端目标沿计算关系求早期导数；参数更新指训练程序用这些导数实际改数。前者的结果不能代替后者。若一个中间活动 h 同时送到两个末端 s1=v1h、s2=v2h，总损失为两项平方损失之和，那么

∂L∂h=(s1−y1)v1+(s2−y2)v2.

两条后路都因 h 改变，影响先相加，再往更早的参数传。这也是后来网络中“反向累计”比为每个权重从头重算整条路径更有用的原因。1986 年论文在一般连接图上同样要求汇合所有后续连接的贡献。(原论文第 534—535 页，式 (4)—(7))

这条乘积可以先自己写成一个十几行的核算，再进四张卡片、两个隐藏单元的完整程序。在 AI教程_配套练习/practice 新建 mine_03.py，先写 import math。只取本章练习中的一条路径：x1 = 1.0、target = 1.0、v = -2.0、b = 1.2；令 a = math.atanh(0.5)，这样 math.tanh(a * x1) 恰为 0.5。这里的人为初值只是为了让本章刚算过的导数能逐项复核，并没有在训练网络。

在文件里定义一个 loss(at_weight)：先算 hidden = math.tanh(at_weight * x1)，再算 score = b + v * hidden，返回 0.5 * (score - target) ** 2。接着按上式用当前活动、残差、v 和 x1 算解析导数；另用 step = 1e-6 算

finite_difference = (loss(a + step) - loss(a - step)) / (2 * step)

两者应都接近 1.2。若符号相反，先检查负的末端权重 v 以及残差 score - target = -0.8；若相差明显，检查你是否把 1 - hidden ** 2 写成 1 - hidden。从 Open-Lab.ps1 进入工程后运行 python ..\AI教程_配套练习\practice\mine_03.py。随书完成版的单路径核算可供对照。它只检一条链式导数的实现，接下来的四卡片程序才会把每张贡献相加、除以四，并真的更新九个参数。

让同一批四张卡片走过正向与反向计算

完整的本机程序只用 Python 标准库。参数按角色分别存放：a 是两行、每行两个输入权重；c 是两个隐藏偏置；v 是两个通向末端的权重；b 是末端偏置。正向函数对一张输入给出 z1,z2、h1,h2 和分数 s，下面这段反向计算才使用它们：

_, hidden, score = forward(params, features)
residual = score - target
gradient["b"] += residual / count
for j in range(2):
    gradient["v"][j] += residual * hidden[j] / count
    influence = residual * params["v"][j] * (1.0 - hidden[j] ** 2)
    gradient["c"][j] += influence / count
    for k in range(2):
        gradient["a"][j][k] += influence * features[k] / count

这里 count 为 4，因为四张卡片都参加训练；每项导数除以 4 后才是四张平均损失的梯度。influence 是同一张卡片传到第 j 个隐藏单元、尚未乘输入 xk 的影响。程序把梯度另存，调用 updated 函数才由同一组旧参数做一次更新。这样第一个隐藏单元的改动不会偷偷混进第二个单元本轮应使用的旧活动。

为了检查手写求导时没有把某一行、某一层的符号弄反，程序还做了一个有限差分核算：每次只把九个参数中的一个分别加、减 10−6，用两次损失的差估计该处斜率，再与上式计算出的偏导比较。本机九项中的最大绝对差约 8.05×10−11。数值差分是实现核对，链式推导才说明为什么应得到这些导数；微小差值也不证明未来所有网络训练都正确。

从项目根目录的 PowerShell 终端运行：

$env:PYTHONUTF8='1'
python work/code/two_hidden_units.py

程序先核对手工设计的两单元表示，再从固定的随机种子开始训练同一九参数结构，保存各步的损失、活动、分数和参数。完整结果保留四张卡片的逐项记录；学到的参数写出后又被读回核对。这里四种输入全部用于训练，没有留出第五种二值输入，因此输出只能证明这四点上的表达和训练过程，不能宣布一般图形识别能力。

固定种子 1、步长 0.2、整批更新 600 次后，四张卡片的分数约为 −1,+1,+1,−1，平均平方损失约 6.1×10−13。学到的两个隐藏活动值得看一眼；它们没有被单独告知要取下表中的数：

输入 x 目标 y h1 h2 末端分数 s
(0,0) −1 −0.747 −0.657 约 −1
(1,0) +1 −0.993 0.674 约 +1
(0,1) +1 0.706 −0.983 约 +1
(1,1) −1 −0.751 −0.653 约 −1

两张负例在隐藏活动上很相近；两张正例则各在不同的隐藏单元上显出区别。末端用两项活动的组合给出目标分数。这组具体表示与前面的手工阈值构造不同，却服务于同一四点任务；“中间表示从最终目标学出”在这里有可指认的参数、活动和结果。

有这种结构，也可能没有学成

把所有九个参数设成零，两个隐藏活动与末端分数全是零。由于末端权重 v1,v2 都为零，前段参数的导数也全为零；末端权重的导数含 hj=0，同样为零。四张卡片正负各半，末端偏置收到的残差平均也恰好为零。于是全批平方损失仍是 1/2，九项梯度全为零，按本章规则更新一步也不动。表示能力没有消失，卡住的是这组起点和优化办法的组合。

但“避免全零”还不够。让两个隐藏单元从同一组非零参数开始：a11=a21、a12=a22、c1=c2、v1=v2。任取一张卡片，它们的 z 相同，h 相同；前面已推的导数 ehj 和 evj(1−hj2)xk 因而也逐项相同。四张平均后仍相同，一次按同一步长更新后两组参数继续相同；重复这个推理，多少轮都不会自行分开。此时末端分数实际上只有 s=b+(v1+v2)tanh(a1x1+a2x2+c)：看似两个单元，却只提供前面证明过不能分开异或的一个单调中间量。

程序用 a1=a2=(0.2,0.2), c1=c2=0.1, v1=v2=0.2 亲手检查这条不变关系。600 次整批更新后两组参数依然相同，平均损失约 0.350，四张中仍有一张判错。这里“不能靠继续同样的更新让两个单元分工”来自对称性的推导，不是因为只跑了 600 步。较小但彼此不同的初值能够解除这种精确相等的约束；它们并不保证一定找到好参数。这也解释了 1986 年论文为何在实验中提到用小随机初值打破对称，而无需把随机说成某种会自动创造表示的神秘力量。

但“不是全零、也不完全相同”仍不等于“必定成功”。同一程序把种子改为 3，保持两单元结构、四张卡片、步长 0.2，做完 3000 次整批更新后，损失仍约 0.251，(1,0) 的分数略低于零，(1,1) 略高于零，这两张仍判错。此时九项导数的合成长度约为 0.00124，并不为零；把这次慢而未成功的过程直接命名为“陷入局部极小”，还缺证明。记录只说明这些确定设置在这次运行范围内没有找到前面已知存在的好参数；我们没有从一条曲线证明它永远走不到，也没有把一个成功种子的结果冒充普遍保证。更大的任务会让目标与起点的选择更重要，这些困难以后要结合真实数据和计算预算继续研究。

这一章把两种边界分清了。单条直线的异或困难是表达限制；两处非线性中间活动已有表达能力，但从全零或某些随机起点训练未成功，是优化过程的限制。最终目标怎样分配到早期参数，已能由链式法则和手写程序逐项重建。实际网络一旦有许多层和参数，逐项手写导数很容易抄错。下一章会保留这次已懂的前向式和目标，让 PyTorch 按实际执行的计算关系接手求导、注册参数和执行更新；它不能替我们决定标签、目标或证据能支持多大的结论。

  2. 对一张 x=(1,0) 的卡片，设某隐藏单元当前活动 hj=0.5，通往末端的权重 vj=−2，末端分数 s=0.2，目标 y=1。求 ∂ℓ/∂aj1；步长 0.1 时，训练程序会把 aj1 往哪个方向改？
  3. 先不看运行记录，分析全零参数时每组导数为什么为零；再对上文那组完全相同的非零初值证明：若本轮两组参数相同，下轮也相同。用结果文件核对 600 轮后的关系，说明它为什么与“全零梯度”并非同一个故障。
  4. 看种子 3 的四个分数与终点梯度长度。能说这次结构无法表示异或、陷入局部极小，还是只能说在给定步数内未找到好参数？分别缺什么证据？

核对。第一题代入后 s=(v1a11+v2a21)x1+(v1a12+v2a22)x2+(b+v1c1+v2c2)，仍是线性分数。第二题残差 s−y=−0.8，而 1−hj2=0.75，故导数为 (−0.8)(−2)(0.75)(1)=1.2；按梯度下降更新，该权重减少 0.12。第三题全零时还要用到四个目标正负平衡，才使最后的偏置导数也为零；非零但两单元相同的时候，梯度可以不为零，却由同一公式保证对应两组导数相同，参数只能一起移动。第四题已有手工构造和种子 1 证明这结构能表达异或；种子 3 的记录只证明在 3000 步内仍有两个错误，而非零梯度不足以支持“已经到局部极小”。
