第十五章　选择公理与反向数学

15.1 ZF 上的经典互推

在经典一阶集合论 ZF 的语言与背景中，选择公理、佐恩引理和良序定理存在标准的双向证明：

ZF+AC⊢Zorn,ZF+Zorn⊢AC,
ZF+AC⊢WO,ZF+WO⊢AC.

在适用演绎定理的写法下，

ZF⊢AC↔Zorn,ZF⊢AC↔WO.

这里的内容是：不预设 AC 的 ZF，只要额外给其中一个原则，就可建出另一个。它不是说三句话字面相同，也不是说在所有逻辑基础中都保持同样关系。

15.2 为什么 S+A⊢B 还不够：背景可能已经完成了证明

这是理解“弱背景”最关键的一步。证明关系通常有单调性（弱化）：

S⊢B⟹S+A⊢B.

也就是说，若 S 原先已能推出 B，把额外前提 A 塞进去并不会让证明更有信息量。因此

S+A⊢B

单独出现时，只说“在允许 S 与 A 的前提下可证明 B”；它没有说某份证明一定使用了 A，更没有说 A 是推出 B 的唯一途径。

若同时有

S+A⊢B,S+B⊢A,

而且 S⊢B，那么由割规则（把 S 对 B 的证明接到从 S+B 到 A 的证明上）得到 S⊢A。所以一旦 S 已经证明其中一个，双向互推就会退化为 S 已经证明两个。

最无信息量的例子是

S={P,Q}.

显然 S+P⊢Q 与 S+Q⊢P，但这完全不是 P,Q 之间的新依赖：它们本来就在 S 中。

相反，令

S0={P↔Q}.

在经典命题逻辑中，S0⊬P 且 S0⊬Q：令 P,Q 同时为假便是反例赋值；但

S0+P⊢Q,S0+Q⊢P.

这个玩具例子只展示形式结构，不声称它是深刻数学；它清楚地区分了“背景已分别给出 P,Q”与“背景只给出二者之间的桥梁”。

因此，关于证明强度的严格对象不是一棵特定证明树里有没有写到 A，而是理论的演绎闭包。记

CnC(X)={φ:X⊢Cφ}.

在通常允许割与弱化的演算中，

S+A⊢CB,S+B⊢CA⟺CnC(S∪{A})=CnC(S∪{B}).

左到右的证明是把一侧的“额外公理”先用另一侧推出，再接上原证明；右到左只需把 A,B 各自代入闭包相等式。于是

S⊬A,S⊬B

不是定义，却是说“二者确实各自补上了 S 缺失的同一块力量”时最自然的验收条件。

15.3 真正构造一个弱背景：RCA0 与 ACA0

反向数学不是先把 RCA0 当作神秘名字，再把定理贴上去；它先固定二阶算术语言。可以把它粗略记作

L2={0,1,+,×,<,∈},

其中数变量 m,n,… 取自然数，集合变量 X,Y,… 取自然数的集合，n∈X 表示成员关系。实数、图、序列、有限集和函数都必须被编码为自然数或自然数集合。

标准基底 RCA0 可概括为三部分：

离散有序半环的基本算术+Σ10-归纳+Δ10-理解.

最后一项的示意形式是：若一个集合既可由 Σ10 公式又可由等价的 Π10 公式描述，则该集合存在：

∀n[φ(n)↔ψ(n)] ⟹\ ∃X∀n(n∈X↔φ(n)),

其中 φ 是 Σ10 公式、ψ 是 Π10 公式。直观上，它允许相对参数的可计算构造，却不自动给出任意算术定义的集合。

更强的

ACA0=RCA0+算术理解公理模式

允许对任意不含集合量词的算术公式 θ(n) 形成集合：

∃X∀n(n∈X↔θ(n)).

这里 X 不在 θ 中自由出现，θ 可以带其他数或集合参数。因而 ACA0 能保证诸如停机问题编码集合这类不可计算集合存在，而 RCA0 不行。两者并非只是难度标签，而是明确写出的公理系统；在“可证明内容包含”的通常强度次序中，ACA0 严格强于 RCA0：最小 ω-模型 REC 满足后者，却不满足算术理解。

这也给出“构造弱背景”的可执行模板：

  1. 固定编码、语言和定理的精确版本；
  2. 选择 S=RCA0；
  3. 在 RCA0+A 中构造 B 的证明；
  4. 在 RCA0+B 中反推所需理解原则或直接反推 A；
  5. 最后检查 RCA0⊬A,B，而不是只检查在强理论中它们都为真。

15.4 一个完整标尺：Bolzano--Weierstrass 定理

令 BW 表示一个已固定编码的序列紧致性陈述：

每个有界实数序列都有收敛子列。

这里“实数”通常以快速 Cauchy 有理数列编码，“有界”“子列”“收敛”也都展开为 L2 的公式。对这个标准版本，反向数学给出的恰是完整的两向结果：

ACA0⊢BW.

反向方向不是把系统名 ACA0 当作一条句子，而是指：对算术理解模式的每一个实例的全称闭包 α，都有

RCA0+BW⊢α.

为压缩这两项元理论断言，本书以后写

BW≡RCA0ACA0.

这个 ≡RCA0 是“在背景 RCA0 上等强”的元语言记号，不是对象语言中形如 BW↔ACA0 的单一公式。这不是“二者主题相同”：左边讲实分析的收敛子列，右边讲集合存在。它说明任何在 RCA0 上足以取得所有有界序列收敛子列的原则，也足以取得所有算术可定义集合；反过来，算术理解又足以完成该分析证明。

它同时通过了 15.2 节的反冗余检验。若 RCA0⊢BW，再接上刚才的反推，RCA0 就会证明每一个算术理解实例；但其可计算 ω-模型 REC 不满足算术理解。因此背景不是暗中已经把 BW 证明掉了。

15.5 Hall、Marshall Hall 与“必须写出版本”的教训

组合数学正好说明：一个模糊的定理名不够用来谈证明强度。先区分三个尚待精确编码的层次：

  • 𝖧fin：有限婚配问题满足 Hall 条件，则有覆盖左侧的匹配；
  • 𝖧count：可数无限婚配问题满足每个有限子集的 Hall 条件，则有这种匹配；
  • 𝖧eff：在给定的有效性、局部有限性或扩张 Hall 条件下的无限版本。

其中 Hall 条件写为

∀F⊆finB|N(F)|≥|F|.

这三行的量词范围、边关系如何编码、匹配是否作为集合存在、有限性落在何处、局部有限性是单纯存在还是有效给出，都会改变反向数学强度。当前书中可以无歧义使用的有限结论是

RCA0⊢𝖧fin,

而 Hirst 的原始研究和后续工作表明：某些逐字写明的 Marshall Hall 型无限版本会反演到 ACA0 或 WKL0；例如后续文献对“高度递归编码加扩张 Hall 条件”的一个精确版本给出 WKL0 等价。这里的 𝖧count 和 𝖧eff 只是分类标签，绝不自动指向其中任何一条精确反演。重点不是记住三个缩写，而是看见一个必要的出版规范：

绝不能把“Marshall Hall 定理”等未写明版本的名称直接断言为 ACA0 等价。

“可数个有限集合”“所有有限子族”“局部有限”“可计算给出”的不同组合会产生不同定理。若要在某篇论文或一道题中使用精确反演，必须给出原定理编号，并逐字对照其编码与 Hirst 或后续文献所分析的版本；本书不把这个版本差异伪装成一个单一结论。

15.6 反向数学的边界

至此可回头正确理解

RCA0⊢A↔B.

它表示相对于该精确基底的可证明等价。不同的基底、不同版本的定理、不同编码方式都可能改变结论；因此“来自不同领域的两个定理都很深”并不足以推出它们在反向数学中等强。更不能因为在 ZFC 或另一套强背景里两个结论都已可证，便把平凡的理论内互推误当作一次反向数学反演。

若 B 在这句话中不是一个句子而是诸如 ACA0 的系统名称，则上式不再是可直接解析的对象语言公式；应改写成 15.4 节那样的“两个方向分别成立”的元理论陈述。
