13. 禁忌搜索：有记忆的局部搜索

普通下降型局部搜索的规则通常是：只有邻居更好才移动。若当前解满足

f(y)≥f(x);∀y∈N(x),

它就停止。但这只证明 x 在所选邻域内是局部最优，并不证明它是全局最优。

禁忌搜索的核心不是模仿某种动物，而是一个朴素而有力的想法：

下一步即使暂时更差，也可以走；但把最近做过的修改暂时列为禁忌，防止立刻后悔、来回打转。

13.1 禁忌的通常不是整个解，而是移动属性

假设当前排列是

(1,2,3,4,5),

本轮交换第 2、4 个位置：

(1,2,3,4,5)⟶(1,4,3,2,5).

可以把“撤销这次交换”或“把任务放回原位置”设为禁忌。若禁忌期限为 3 轮，可记为：

(2,4):3⟶(2,4):2⟶(2,4):1.

期限结束后删除该记录。这个期限叫禁忌任期或 tabu tenure。

为什么不总是存整个解？因为完整解可能很大，比较和存储代价高。更常见的是存：

  • 最近交换的元素；
  • 被删除或新加入的边；
  • 任务原来的机器或位置；
  • 本轮移动的反向操作。

禁忌属性定义不当会“禁得太少”或“误伤太多”，它是算法设计的一部分。

13.2 允许集合与最好允许移动

设禁忌表为 T，从当前邻域中筛出允许集合：

A(x)={y∈N(x):move(x,y)∉T}.

标准禁忌搜索通常选择允许集合中的最好者：

xk+1=argminy∈A(xk)f(y).

关键是它不要求

f(xk+1)<f(xk).

它只要求这是当前允许移动中最好的一个。因此算法可以越过一道短暂的“上坡”，进入另一个更有希望的区域。与此同时，另存

x*=argmin0≤t≤kf(xt)

作为历史最好解。当前解与历史最好解必须分开。

13.3 特赦准则：禁忌不是机械死规则

若某个移动虽然处于禁忌状态，却能产生新的历史最好解：

f(y)<f(x*),

仍允许执行，这叫特赦准则或 aspiration criterion。于是允许条件实际是：

move(x,y)∉T 或 f(y)<f(x*).

它防止禁忌表把真正突破性的移动挡在门外。

13.4 一轮到底怎样运算？

构造初始解 x
x_best ← x
tabu ← 空表

while 未达到停止条件:
    生成或抽样邻域 N(x)
    对每个邻居 y:
        检查可行性或计算约束违反
        计算目标值或增量 Δf
        识别 move(x, y) 是否禁忌
        检查是否满足特赦条件
    从允许邻居中选择评价最好的 y_best
    x ← y_best                 # 即使它比上一步差
    若 f(x) < f(x_best):
        x_best ← x
    把本轮移动的反向属性加入 tabu
    所有旧禁忌期限减一，删除到期项
返回 x_best

停止条件可用迭代上限、时间限制、目标评价预算、连续若干轮没有改善历史最好解，或达到已知目标值。不能简单设置成“当前解没有变好就停止”，因为允许暂时恶化正是禁忌搜索的意义。

13.5 一个具体的 TSP 选择回合

假设当前路线长度是 100，生成若干邻居：

移动 新路线长度 是否禁忌 是否产生历史最好
交换 B,C 98 是 否
交换 B,D 101 否 否
交换 C,E 103 否 否
交换 D,E 102 否 否

若交换 B,C 没有触发特赦，就从其余允许移动中选择长度 101 的邻居。虽然

101>100,

仍然前进。之后可能出现：

100→101→99→94→87.

普通下降搜索可能停在 100；禁忌搜索通过一次暂时变差进入了更好的区域。当然，这只是说明机制能够做到，并不保证每次暂时变差都会得到回报。

13.6 2-opt 为什么常和 TSP 禁忌搜索配合？

2-opt 删除两条边 (a,b),(c,d)，加入 (a,c),(b,d)，并反转中间路线段。路线长度变化可增量计算：

ΔL=dac+dbd−dab−dcd.

不必每次重新计算整条路线。若 ΔL<0，路线变短。禁忌属性可以设为“短期内禁止重新加入刚删除的边”，而特赦规则允许产生历史最短路线的禁忌移动。

这说明算法效率不仅来自搜索策略，也来自增量评价。若邻域有 O(n2) 个移动，而每个移动都重新计算 O(n) 的总路程，一轮可能达到 O(n3)；使用常数时间的边差计算可显著降低成本。

13.7 车辆容量约束怎么办？

车辆路径中每条路线 Rk 可能要求：

∑i∈Rkqi≤Q.

把顾客移到另一辆车上后可能超载。此时必须明确选择：

  • 直接禁止超载邻居；
  • 把顾客修复到其他路线；
  • 允许超载，并把 max{0,∑i∈Rkqi−Q} 加入惩罚；
  • 设计只会生成容量可行邻居的移动。

禁忌搜索不会自动替你决定约束策略。

13.8 禁忌期限、强化与多样化

禁忌期限 L 太小，搜索可能循环：

x1→x2→x3→x1.

L 太大，又会禁止过多移动。可以固定 L=7，也可以每轮取

Lk~U(Lmin,Lmax),

或在停滞时动态增大。

更成熟的禁忌搜索还会用长期记忆：

  • 强化搜索：回到优秀解附近，保留好解中频繁出现的结构；
  • 多样化搜索：惩罚过度使用的边或移动，前往较少访问的区域；
  • 重启：从精英解、随机解或新的构造解重新出发；
  • 多邻域：在 swap、insert、2-opt 等邻域之间切换。

可以用频率记忆构造：

f~(y)=f(y)+λFfreq(move(x,y)),

使过度使用的移动暂时变得不那么有吸引力。

13.9 禁忌搜索与模拟退火的区别

两者都允许更差解，但机制不同：

模拟退火 禁忌搜索
接受较差解 按 e−Δf/T 随机接受 选择允许邻域中的最好移动
跳出局部最优的主要工具 温度与随机性 记忆、禁忌与特赦
是否系统检查邻域 通常只抽一个或少量邻居 常枚举或抽样较大邻域
关键参数 初温、降温、邻域尺度 禁忌属性、期限、特赦、邻域
典型气质 “偶尔走一条坏路” “有计划地不走回头路”

所以禁忌搜索的本质可以概括为：

下一步不必更好，但不能轻易走回头路
