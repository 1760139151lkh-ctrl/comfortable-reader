第十三章　先把“系统”定义清楚：局部规则也是方程

前面的章节一直在回答“有限元如何近似一个连续问题”。但读者很容易在这里产生一个合理的联想：

有限元、有限差分和元胞自动机，似乎都把空间切成小块，再用附近的信息更新每个位置。它们是不是同一种方法？

这个联想抓住了共同的外形，却还没有抓住严格的分类标准。要把区别说清楚，最好先暂时忘掉“谁把离散规则当作基本规律”这句话，从最底层定义“系统”。

13.1 任何动力系统都从两样东西开始

数学上，一个动力系统最核心的对象只有两样：

  1. 系统在某一时刻可能处于什么状态；
  2. 状态按照什么规律变化。

离散时间系统可以写成

Xn+1=F(Xn).

连续时间系统可以写成

dXdt=G(X).

这里的 X 可以是一个数、一个有限维向量、一个函数，也可以是整个空间里所有位置的状态集合。

如果把所有格点的状态放在一起，例如

Xn=(xin)i∈Λ,

那么只要给定

Xn+1=F(Xn),

就已经定义了一个完整的系统。用一句话压缩就是：

系统=状态空间+演化映射.

因此，有限差分得到的离散方程当然可以被当作某个离散世界的基本规律；生命游戏的生存规则也当然是一种离散方程。把“它原本是为了近似连续方程”当作通常背景是有用的，但不能把它当成数学上的本质边界。

13.2 局部性是结构，不是“系统”的定义

许多物理系统具有局部相互作用，例如

xin+1=f(xi−1n,xin,xi+1n).

但系统也可以是非局部的。例如每个位置都根据全体位置的平均值更新：

xin+1=1N∑j=1Nxjn.

它仍然是一个完全合法的动力系统，只是更新所依赖的范围不是有限邻域。

还可以有全局约束，例如

∑i=1Nxi=1.

所以“系统由局部组成”是很多自然模型的重要结构，却不是系统的定义。元胞自动机、许多偏微分方程和显式有限差分格式都具有局部性；但局部性本身并不能把三者变成同一个对象。

13.3 生命游戏当然就是离散方程

设二维格点上的元胞状态为

xi,jn∈{0,1},

其中 1 表示活细胞，0 表示死细胞。取中心格点周围的八个位置为邻域，记活邻居数量为

mi,jn=∑(p,q)∈N(i,j)xp,qn.

生命游戏的规则可以用三句话写成：

  • 若当前是活细胞，且 mi,jn 为 2 或 3，下一时刻仍存活；
  • 若当前是死细胞，且 mi,jn=3，下一时刻复活；
  • 其他情况下一时刻死亡。

也可以把它压缩成

xi,jn+1=f(xi,jn,mi,jn).

这当然是一个方程，只不过它的状态取有限离散值，时间按步推进，函数 f 是分段逻辑函数。

看一个局部计算就很直观。若某个活细胞的八邻域中恰好有三个活细胞，

0 1 0
1 1 0
0 1 0

中间的 1 看到三个活邻居，因此下一步仍为 1。如果同一个中心细胞只看到一个活邻居，它就会因为“孤独”变成 0；若看到四个以上，则因为“拥挤”变成 0。规则没有因此失去方程身份，它只是从代数运算换成了有限状态的逻辑映射。

所以，生命游戏和显式有限差分之间没有本体论上的鸿沟。二者都可以写成：

下一时刻的局部状态=当前邻域状态的函数.

真正要问的是：状态空间是什么、邻域如何选、更新是否同步、原问题怎样解释，以及我们要研究的是数值逼近误差还是规则自身的涌现行为。

13.4 经典元胞自动机的严格定义

一个经典的 d 维确定性元胞自动机通常包含以下数据。

（1）格点空间

Λ=Zd.

每一个 i∈Λ 是一个元胞位置，因此空间本身是离散的。

（2）有限状态集合

设

A={a1,⋯,aq}.

每个元胞状态属于 A。例如二值生命游戏使用 A={0,1}，森林火灾模型可以使用

A={空地,树木,燃烧}.

整个系统的一个构型是一个映射

c:Zd⟶A.

（3）有限邻域

选择有限集合

N={n1,⋯,nk}⊂Zd.

位置 i 的邻域位置就是 i+n1,⋯,i+nk。

（4）局部更新函数

f:Ak⟶A.

它读取邻域内 k 个状态，输出中心元胞下一时刻的状态。

（5）同步的全局更新

定义全局映射

F:AZd⟶AZd,

满足

F(c)(i)=f(c(i+n1),⋯,c(i+nk)).

系统按

cn+1=F(cn)

演化。经典定义通常还要求空间各点使用同一个局部规则，并且所有元胞同步更新。异步元胞自动机、概率元胞自动机、连续状态元胞自动机都是在这些条件上做了扩展。

13.5 “元胞”和有限元“单元”不是同一个角色

名称相近很容易造成误解。

有限元中的单元，例如三角形 Te，主要承担几何分块、基函数限制、数值积分和局部矩阵计算的任务。单元本身通常不是一个独立的状态载体。

元胞自动机中的元胞则直接携带状态：

xin∈A.

它在每个时间步按照局部规则更新。于是

有限元单元≠元胞自动机元胞.

二者都把空间分块，但分块之后承担的数学角色完全不同：一个服务于函数空间和积分，一个服务于局部状态和演化。
