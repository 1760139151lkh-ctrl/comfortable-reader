# 第四条记录出现以后

## 新记录改变的是哪一个问题 {#new-record}

上一章的三条人造记录恰好在一条直线上。现在仍用同样的预测 ŷ = wx + b，却给它第四条记录 (2, 9)。表中的 (2, 5) 没有消失；同一个 x 有两个不同 y。任何确定的函数都不能在 x = 2 时同时输出 5 和 9，所以再多更新也不能使这四条训练误差**全部**为零。这是数据要求与表示之间的冲突，不能归咎于步长不够大。

让程序按平均平方误差更新时，它在四个目标之间寻找折中。第四条在 x = 2 处造成较大误差，也会通过梯度乘上 x，推动 w；b 同时影响每条预测。因而你应当观察全部四条误差，而不是只看新点是否终于被猜对。

## 用另一种条件检查结论

试着把步长变小而保持四条记录不变。开始那一步会更短，但 x = 2 仍有两个目标，误差全为零的不可能性不会改变。若反过来只保留 (2, 9) 而移除 (2, 5)，那就变成了另一批数据；不能把“改数据”和“再训练久一点”混作同一次试验。

这个小模型的价值在于把计算链看清：数据决定误差信号，目标告诉程序要减小什么，梯度表示当前参数附近的改动方向，优化器步骤才改变下次可复用的 w、b。它没有证明真实世界本来是直线，也没有根据三点验证对未见数据的可靠性。要作后者的判断，还得取得与训练记录独立的测量和评价。
