# 一条直线怎样从数据中改变

我们先有三条人工写下的记录。第一列是输入 x，第二列是想让程序接近的数 y。它们不是自然实验，也不是别人的数据集。

| x | y |
|---:|---:|
| 0 | 1 |
| 1 | 3 |
| 2 | 5 |

数据的三个答案恰好都在 y = 2x + 1 上。但程序起初并不知道系数 2 和常数 1；从这三个数直接抄出一条线，也无法让我们看见“参数被学习”是怎样发生的。我们先选一个可计算的规则，再跟踪它每一步怎么变。

## 先选能表达的预测

让程序给输入 x 算出预测值 ŷ = wx + b。w 控制 x 增加 1 时预测改多少，b 是 x = 0 时的预测；它们是在多条记录之间**共享**的参数。一次预测 ŷ 是临时算出的值，不能把它叫作保存下来的模型。我们的初始条件是 w = 0、b = 0，因此面对 x = 2，它先给出 0 而不是 5。

现在需要一个量，告诉我们这一整批预测离三条答案有多远。选择平均平方误差 L = [(ŷ₁−y₁)² + (ŷ₂−y₂)² + (ŷ₃−y₃)²] / 3。平方让正负误差不能互相抵消，也让较大的偏差受到更强惩罚；平均使这批记录的数量明确。换成绝对误差也可以衡量，但更新公式会改变。这里选择平方不是宣布世界只能用这种目标。

## 一次更新真的改动什么 {#first-update}

保持三条 (x, y) 固定，只有 w、b 会改变。把每条误差 ŷ−y 沿共同参数合起来，可得 ∂L/∂w = (2/3)∑(ŷᵢ−yᵢ)xᵢ，∂L/∂b = (2/3)∑(ŷᵢ−yᵢ)。第一个梯度多乘 x，是因为改 w 对输入 x 大的预测影响较大；改 b 对每条预测都增加相同的量。

从 w = b = 0 开始，三条误差分别是 −1、−3、−5，所以初始 L = 35/3。梯度分别为 −26/3、−6。若暂选步长 η = 0.12，程序完成一次更新以后才得到 w = 1.04、b = 0.72。先算出梯度，并不等于已经修改了参数；更新是 w ← w − η∂L/∂w、b ← b − η∂L/∂b 这两次赋值。

## 一份新的记录在等待 {#try-variant}

若现在添上 (2, 9)，原来三点中 x = 2 的答案是 5，而新点同样输入却要 9。一条确定的直线不可能同时给 x = 2 两个不同预测。它仍能选一个折中，让平均平方误差尽量小；这种“训练能继续”与“模型能完全满足所有记录”是两件事。可以先尝试变体再去下一章解释这项边界。
