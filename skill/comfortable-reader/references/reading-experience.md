# 从长期阅读推导设计

复杂书或阅读器改动时先读本文件。先理解读者需要完成的事情，再选排版与交互；参数和实例是起点，不是跨书籍的固定审美。

## 连续性与密度

- 读者能迅速找到当前行、下一行和下一段。段落节奏稳定，标题与紧随内容共同出现；普通长章节不应连续数屏只有几个词。
- PDF 页数、屏幕栏数、全书内容位置是三个量。大量空白先检查碎段、固定宽度、过度禁止分页与错误列宽，不先把全书字号缩小。
- Auto 为连续阅读选择合理行长；很多栏是用户主动选择的概览。十栏在窄窗中自然更小，不能宣称所有栏数都同样适合数小时阅读。
- 测量普通正文的每行词数分布、每栏内容量和连续空白区域。标题、诗歌、列表、短标签不是普通正文异常，不用一个阈值机械判整书。

## 语义决定怎样断开

| 内容 | 必须保留的关系 | 超过一栏时 |
|---|---|---|
| 正文 | 句子、段落、强调、上下标 | 按行自然流动，控制孤行 |
| 算法/长代码 | 步骤、缩进、注释、行号、分支范围 | 在完整步骤/语义行间续排，短 case 组保持一起 |
| 表格 | 列对应、空格、行标题、合并格 | 长表按行续排并重复真实表头；过宽关系表提供可选中文字的详情 |
| 数学 | 运算范围、定界符、编号、标点 | 行内参与正文；独立式保全结构，适度适配，过宽时放大阅读 |
| 图与图注 | 完整图形、图号、全部说明、引用关系 | 短图注随图；长图注以正常字号续排并保持语义关联 |

不要将上表理解为任意拆分：单行、公式和短分支组仍有自己的边界。标题中的长词或不换行空格需要窄栏换行退路，防止字形侵入下一栏。长算法和长图注不能因为总高度超过一栏就缩成微字。

## 字体与主题

阅读器拥有正文、数学、代码和界面字体角色。新重建书用语义标签、相对字号及 `--reader-*` 变量继承它；不为每本导入书硬编码一套 px 字体。数学保留专门字体及正体/斜体语义；伪代码也可使用适合符号和缩进的衬线字体。出版社模式保留已有 EPUB 的有效设计。

主题切换替换一个受控样式表，不追加旧规则。测试衬线/无衬线/出版社来回切换后的计算字体、数学基线与内容位置。字体造成的字距不能通过擅改原文字词修补。

真实插图保留原始颜色与视觉编码；深色主题使用克制的纸面容器、边框、边距和主题色图注，不机械反相或删除图中白底/文字。点击图看原图；公式与表格详情仍为可选择复制的 MathML/HTML，不能截图替代。

## 交互与性能

高频工具在正文之外稳定占用窄区域；展开不遮挡首行，也不推挤全文。临时内容面板可浮动，主动停靠时必须真正为正文让出空间。书库、目录、搜索、设置由点击或快捷键打开，点外部/Escape 关闭；hover 只提供轻微反馈，不能改变大块几何、黏着指针或突然遮正文。避免按钮位移、呼吸动画及阻塞阅读的过渡。

文字按钮与图标按钮要按实际内容分别定尺寸。曾有对话框文字按钮继承图标按钮的固定宽高，文字竖排且可见区域大于命中区域；修样式时保留图标按钮的紧凑尺寸，让文字按钮按内容扩展，并在窄屏检查换行、`scrollHeight/clientHeight` 与真实命中框。主题切换后读取计算后的前景、背景和对比度，核实组件确实使用当前主题变量；源 CSS 写了变量不等于最终文字可读。短视口还要滚动面板自身到最后一项，实际试滚轮、键盘焦点和关闭，不能只看窄宽截图。

实际操作侧栏、滚轮、键盘、目录、搜索、内部链接、返回、字体、主题、窗口变化和重开。分别观察打开、字体/图片稳定、章节跳转、搜索和后台索引耗时。索引不能随每次栏数变化重建。UI 工具捕获其他窗口时，不把它当阅读器证据。

搜索可用 NFKC 将 `ﬁ` 等连字匹配为普通输入，但必须保留归一化字符到原文本位置的映射，才能生成正确 CFI；不修改源书来适应搜索。目录保留原书完整层级，包括版权等非 heading 目标。跳到图、数学、表格也要落到真实元素。

## 验证方法

选前、中、后部的普通正文、密集数学、长算法、表格、完整图注、练习/列表、目录、参考文献和索引。先用样本验证机制，再做全书结构审计和差异队列；不逐页人工翻一千页，也不用几张漂亮截图证明全书正确。

把体验转成可复验条件：相邻栏内容连续，字体变化后目标句仍可见，标题不串栏，算法步骤仍可读，长图注未缩到几像素，resize 无漂移，搜索能返回原处。发现模式性错误就检查同类对象，修规则后重测受影响部分。

截图显示外观，DOM 与计算样式给出布局和可访问状态，点击、滚动、Tab/Escape 等操作给出可达性。绑定同一构建、视口和内容身份记录这三类证据；有源码改动但尚未重测时写“待验”，不要把局部样式试验当正式修复通过。
